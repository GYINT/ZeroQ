# 3A5WHY 不合格遏制处理流程

> **定位**：基于「三现（3A: 现场/现物/现实）→ 五问（5WHY: 发生·流出·系统三链）→ 三流遏制（库存/在途/在制）→ 系统预防（过程控制+流程管理）」的结构化问题解决闭环。适用于来料/过程/客诉三类不合格的遏制与根除。与 QCM 现有工具的关系：5WHY 应用实例（`knowledge-base.md` #5）的单链深化版 + 8D D4-D6 的细化版 + QRQC 的跟进闭环版。

## 原则

不合格不放过、不二次流入、不复发——用三链 5WHY 分别锁定**发生根因**（为什么出现）、**流出根因**（为什么没被拦截）和**系统根因**（为什么体系允许），治理追踪、遏制追溯覆盖三站（库存/在途/在制），最终预防落在过程控制面+流程管理面。

## 流程分步

### ① 问题定义与现物确认（D0–D1）

- **上级门控**：↑ 不合格已发现（来料批退/过程异常/客诉），已隔离
- 输入：← 异常现象描述 + 物料/批次/供应商信息
- 动作：定义异常现象 → 调阅图面/规格/标准 → 现场现物确认 → 记录失效模式与机制
- 判据：现象可量化（有实测数据）；图面/规格/现状三方对照
- 产出→下步输入：不合格遏制处理报告（定义面填写：异常/批次/料件/厂商/需求/现状/FM 机理）
- 责任角色：发现者（IPQC/IQC/CQE）填写 / 质量工程师 核实
- KPI：定义完成 ≤ **D1**（约 8h）

### ② 围堵与风险遏制（D1–D2）

- **上级门控**：↑ 问题定义已确认
- 输入：← 不合格批号 + 追溯信息
- 动作：三站追溯排查 → 库存品冻结复检 → 在途品拦截退回 → 在制品追溯隔离 → 填写遏制措施记录
- 判据：三站全覆盖（不允许跳过任一站）；排查有证据（复检记录/拦截通知/追溯截图）
- 产出→下步输入：围堵遏制记录（含三站排查结果+遏制措施+责任人）
- 责任角色：质量工程师 主责 / 仓库·制造·采购 执行
- KPI：三站排查完成 ≤ **D2**（约 24h）；遏制覆盖 = **100%**

### ③ 3A5WHY 根因分析（D2–D4）

- **上级门控**：↑ 围堵已完成，异常件已取样，数据可追溯
- 输入：← 不合格报告 + 围堵记录 + 失效分析数据
- 动作：按三链逐条 5WHY 下钻：

  | 支链 | 问什么 | 目标深度 | 典型落点 |
  |------|--------|---------|---------|
  | **发生链** | 为什么出现这个缺陷 | Why1→Why5 | 技术根因（如镀层厚度不足、参数偏移） |
  | **流出链** | 为什么没被拦截 | Why1→Why5 | 探测根因（如检具缺失、抽检频率不足） |
  | **系统链** | 为什么体系允许 | Why1→Why5 | 管理根因（如PFMEA漏项、规范未定义） |

- 判据：每条链 ≥ 3 层（典型 5 层）；每层有证据（非猜想）；三链缺一不可
- 产出→下步输入：3A5WHY 分析表（三链×5层 + 失效结论）
- 责任角色：质量工程师 主导 / 技术·制造·设备 协同
- KPI：分析完成 ≤ **D4**（约 48h）；三链覆盖 = **100%**
- **子级里程碑**：
  - M1 发生链完成 + 证据确认 → D2 末
  - M2 流出链完成 + 证据确认 → D3 中
  - M3 系统链完成 + 三链交叉评审 → D4 末

### ④ 纠正措施（临时 + 永久）（D4–D8）

- **上级门控**：↑ 三链根因已锁定
- 输入：← 3A5WHY 分析表
- 动作：
  - **临时纠正措施**：针对发生面和流出面，短期内遏制进一步损失
  - **永久纠正措施**：针对发生面和流出面，根除根本原因
- 判据：临时措施 24h 落地；永久措施经小批验证；发生面+流出面均有对应
- 产出→下步输入：纠正措施记录（含 CA/PA + 责任 + 完成时间）
- 责任角色：质量工程师 主责纠正方案 / 责任部门 执行
- KPI：临时措施 ≤ **24h**；永久措施验证通过 ≤ **D8**
- **子级里程碑**：
  - M1 临时措施实施 → D4 末
  - M2 永久措施方案确定 → D6 末
  - M3 小批验证完成 → D8 末

### ⑤ 系统预防（过程控制面 + 流程管理面）（D8–D14）

- **上级门控**：↑ 纠正措施已验证通过
- 输入：← 纠正措施验证数据
- 动作：
  - **过程控制面**：更新控制计划、PFMEA、作业指导书（防同类事件）
  - **流程管理面**：审视管理体系缺口，更新流程文件、培训计划、标准化
- 判据：过程控制面 + 流程管理面各 ≥ 1 项可执行预防措施；措施已纳入体系文件
- 产出→下步输入：系统预防记录 + 标准化文件更新 + 横向展开（同类产品/工序）
- 责任角色：质量工程师 主责 / 技术·制造·体系 协同
- KPI：措施完成 ≤ **D14**；横向展开覆盖率 = **100%**

> **定位**：PD（Product Development）在产品开发端用质量工具链串起"需求→设计→验证→量产"全线，上步产出即下步输入（APQP 五阶段 + 克劳士比预防前移）。本章按 QCM 默认精简格式（上级门控打头 + 子级里程碑列表 + 周期里程）输出。

## 流程分步

### ① 需求澄清（W1–W2） | 工具：VOC + CTQ Tree
- **上级门控**：↑ 客户需求已采集，立项批准已签核
- 输入：← 客户原始需求
- 动作：采集→分类→排序，提取关键质量特性
- 判据：CTQ 可测量、客户签字确认
- 产出→下步输入：CTQ 清单（量化含公差）
- 责任角色：PD 主责 / 产品经理 协同
- KPI：CTQ 客户确认率 = **100%**
- **子级里程碑**：
  - M1 需求采集完成 → W1 末
  - M2 CTQ 分类排序完成 → W2 中
  - M3 客户签字确认 → W2 末

### ② 方向分解（W3–W4） | 工具：QFD 质量屋
- **上级门控**：↑ CTQ 清单已客户签字
- 输入：← CTQ 清单
- 动作：CTQ → 可测量技术特性 + 目标值，建 HOQ
- 判据：映射率 100%；强相关标`◎`
- 产出→下步输入：技术特性矩阵（目标值 + 权重）
- 责任角色：PD 主责 / DQE 协同
- KPI：映射率 = **100%**；HOQ 完整性 ≥ **80%**
- **子级里程碑**：
  - M1 HOQ 左墙+天花板完成 → W3 末
  - M2 相关矩阵+权重完成 → W4 中
  - M3 设计目标发布评审 → W4 末

### ③ 因素识别（W5） | 工具：P-Diagram 参数图
- **上级门控**：↑ 技术特性矩阵已评审
- 输入：← 技术特性矩阵
- 动作：识别理想函数 y=f(x,z) 中控制因素 x、噪声因素 z
- 判据：噪声覆盖 5 类（外部/内部/退化/客户/环境）
- 产出→下步输入：P-Diagram 因素汇总
- 责任角色：PD 主责 / DQE 协同
- KPI：噪声覆盖 5/5 类
- **子级里程碑**：短步，不拆

### ④ 风险预防（W6–W9） | 工具：DFMEA 七步法
- **上级门控**：↑ P-Diagram 已评审 + 噪声覆盖 5/5
- 输入：← P-Diagram 因素汇总
- 动作：结构→功能→失效→起因→预防→探测→AP
- 判据：S ≥ 9 必有预防控制，AP 样件前关闭
- 产出→下步输入：DFMEA 矩阵（控制措施 + AP）
- 责任角色：PD 主导 / DQE 协同
- KPI：S>8 关闭率 = **100%**；按期完成率 ≥ **90%**
- **子级里程碑**：
  - M1 结构树完成 → W6 末
  - M2 失效链+S9-10 识别 → W7 末
  - M3 预防/探测措施草稿 → W8 末
  - M4 AP 高风险关闭+评审 → W9 末

### ⑤ 验证计划（W10–W18） | 工具：DVP&R
- **上级门控**：↑ DFMEA 高风险关闭 + 设计评审通过
- 输入：← DFMEA 控制措施
- 动作：为每项高风险/关键特性制定验证方案
- 判据：样品 ≥ 30；每项措施有验证节点
- 产出→下步输入：DVP&R 验证结果（合格/不合格清单）
- 责任角色：PD 主责 / DQE·测试 执行
- KPI：DVP 按期完成率 = **100%**；DV 一次通过率 ≥ **85%**
- **子级里程碑**：
  - M1 验证方案审批完成 → W10 末
  - M2 样品制作+测量 → W12–W16
  - M3 DV 测试完成 → W17 末
  - M4 验证报告评审通过 → W18 末

### ⑥ 生产准备（W19–W22） | 工具：控制计划 + PPAP
- **上级门控**：↑ DVP&R 全部通过 + 设计冻结
- 输入：← DVP&R 验证确认的设计输出
- 动作：CTQ → 过程参数/检具/抽样/反应计划，提交 PPAP
- 判据：控制计划覆盖所有 CTQ；量具 Gage R&R < 10%（示例）**
- 产出→下步输入：控制计划 + PPAP 批准
- 责任角色：PD 与质量共担 / SQE 协同
- KPI：PPAP 一次通过率 ≥ **90%**；CTQ 覆盖率 = **100%**
- **子级里程碑**：
  - M1 控制计划草稿+粗流程 → W19 末
  - M2 检具设计+MSA 完成 → W20 末
  - M3 试产+问题点关闭 → W21 末
  - M4 PPAP 提交并批准 → W22 末

### ⑦ 能力确认（W23） | 工具：Cpk + SPC 控制图
- **上级门控**：↑ PPAP 签署批准 + SOP 发行
- 输入：← 控制计划（规格限）
- 动作：量产首件/首批做短期 Cpk，建控制图基线
- 判据：Cpk ≥ 1.33（示例阈值，依客户规格）；特殊原因 24h 响应
- 产出：量产 Cpk 基线 + 控制图监控标准
- 责任角色：PD 交底 / PQE·制造 接收
- KPI：首月关键特性 Cpk ≥ 1.33 达成率 ≥ **95%**
- **子级里程碑**：短步，不拆

# QCM 冲突治理原则

## 冲突治理原则（模式提炼）

1. **跨组同名概念 → 双向引用**：同一概念出现在不同组，加交叉引用而非重复展开（如 C1/C2）
2. **同义词反复 → 去重留一**：同一内容出现在多处，选一处展开+其余引用（如 C3）
3. **术语同名不同义 → 加限定标注**：同一术语在不同上下文含义不同，加前缀说明（如 C5/C6）
4. **自我违反 → 立即修复**：框架自身违反自身原则，优先级最高（如 C7）
