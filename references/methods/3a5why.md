# 3A5WHY 不合格遏制处理流程

> **别名**：`problem-solving.md`（methods/）已废弃合并至本文件（2026-08-22，其 1–118 行与本文件逐字重复）。请勿再新建 `problem-solving.md` 或从别处引用之。详见 `problem-solving.md` 头部 DEPRECATED 标记。

> **定位**：基于「三现（3A: 现场/现物/现实）→ 五问（5WHY: 发生·流出·系统三链）→ 三流遏制（库存/在途/在制）→ 系统预防（过程控制+流程管理）」的结构化问题解决闭环。适用于来料/过程/客诉三类不合格的遏制与根除。与 QCM 现有工具的关系：5WHY 应用实例（`tools-examples.md` #5）的单链深化版 + 8D D4-D6 的细化版 + QRQC（##D23）的跟进闭环版。

## 原则

不合格不放过、不二次流入、不复发——用三链 5WHY 分别锁定**发生根因**（为什么出现）、**流出根因**（为什么没被拦截）和**系统根因**（为什么体系允许），治理追踪、遏制追溯覆盖三站（库存/在途/在制），最终预防落在过程控制面+流程管理面。

## 流程分步

### ① 问题定义与现物确认（D0–D1）

- **上级门控**：↑ 不合格已发现（来料批退/过程异常/客诉），已隔离
- 输入：← 异常现象描述 + 物料/批次/供应商信息
- 动作：定义异常现象 → 调阅图面/规格/标准 → 现场现物确认 → 记录失效模式与机制
- 判据：现象可量化（有实测数据）；图面/规格/现状三方对照
- 产出→下步输入：不合格遏制处理报告（定义面填写：异常/批次/料件/厂商/需求/现状/FM 机理）
- 责任角色：发现者（IPQC/IQC/CQE）填写 / 质量工程师 核实
- KPI：定义完成 ≤ **D1**（约 8h）

### ② 围堵与风险遏制（D1–D2）

- **上级门控**：↑ 问题定义已确认
- 输入：← 不合格批号 + 追溯信息
- 动作：三站追溯排查 → 库存品冻结复检 → 在途品拦截退回 → 在制品追溯隔离 → 填写遏制措施记录
- 判据：三站全覆盖（不允许跳过任一站）；排查有证据（复检记录/拦截通知/追溯截图）
- 产出→下步输入：围堵遏制记录（含三站排查结果+遏制措施+责任人）
- 责任角色：质量工程师 主责 / 仓库·制造·采购 执行
- KPI：三站排查完成 ≤ **D2**（约 24h）；遏制覆盖 = **100%**

### ③ 3A5WHY 根因分析（D2–D4）

- **上级门控**：↑ 围堵已完成，异常件已取样，数据可追溯
- 输入：← 不合格报告 + 围堵记录 + 失效分析数据
- 动作：按三链逐条 5WHY 下钻：

  | 支链 | 问什么 | 目标深度 | 典型落点 |
  |------|--------|---------|---------|
  | **发生链** | 为什么出现这个缺陷 | Why1→Why5 | 技术根因（如镀层厚度不足、参数偏移） |
  | **流出链** | 为什么没被拦截 | Why1→Why5 | 探测根因（如检具缺失、抽检频率不足）；流出管控方案经 **four-aspect-evaluation（四性评估：执行/教育/标准/监督）** 验证落地性 |
  | **系统链** | 为什么体系允许 | Why1→Why5 | 管理根因（如PFMEA漏项、规范未定义） |

- 判据：每条链 ≥ 3 层（典型 5 层）；每层有证据（非猜想）；三链缺一不可
- 产出→下步输入：3A5WHY 分析表（三链×5层 + 失效结论）
- 责任角色：质量工程师 主导 / 技术·制造·设备 协同
- KPI：分析完成 ≤ **D4**（约 48h）；三链覆盖 = **100%**
- **子级里程碑**：
  - M1 发生链完成 + 证据确认 → D2 末
  - M2 流出链完成 + 证据确认 → D3 中
  - M2.5 流出管控方案 four-aspect-evaluation 四性评估（执行/教育/标准/监督）→ D4 初
  - M3 系统链完成 + 三链交叉评审 → D4 末

### ④ 纠正措施（临时 + 永久）（D4–D8）

- **上级门控**：↑ 三链根因已锁定
- 输入：← 3A5WHY 分析表
- 动作：
  - **临时纠正措施**：针对发生面和流出面，短期内遏制进一步损失
  - **永久纠正措施**：针对发生面和流出面，根除根本原因
- 判据：临时措施 24h 落地；永久措施经小批验证；发生面+流出面均有对应
- 产出→下步输入：纠正措施记录（含 CA/PA + 责任 + 完成时间）
- 责任角色：质量工程师 主责纠正方案 / 责任部门 执行
- KPI：临时措施 ≤ **24h**；永久措施验证通过 ≤ **D8**
- **子级里程碑**：
  - M1 临时措施实施 → D4 末
  - M2 永久措施方案确定 → D6 末
  - M3 小批验证完成 → D8 末

### ⑤ 系统预防（过程控制面 + 流程管理面）（D8–D14）

- **上级门控**：↑ 纠正措施已验证通过
- 输入：← 纠正措施验证数据
- 动作：
  - **过程控制面**：更新控制计划、PFMEA、作业指导书（防同类事件）
  - **流程管理面**：审视管理体系缺口，更新流程文件、培训计划、标准化
- 判据：过程控制面 + 流程管理面各 ≥ 1 项可执行预防措施；措施已纳入体系文件
- 产出→下步输入：系统预防记录 + 标准化文件更新 + 横向展开（同类产品/工序）
- 责任角色：质量工程师 主责 / 技术·制造·体系 协同
- KPI：措施完成 ≤ **D14**；横向展开覆盖率 = **100%**
