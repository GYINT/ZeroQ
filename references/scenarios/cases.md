## 一、某通信科技龙头：以客户为中心的大质量体系

### 核心做法
- **以客户为中心**：视质量为企业的生命线，质量即"满足并超越客户需求"；"质量优先、以质取胜"为质量方针，目标是建立覆盖全流程、全价值链的"大质量"体系。
- **IPD（集成产品开发）中的质量门**：将质量要求深度内嵌于 IPD 六个阶段、5 个 DCP、6 个 TR 的每个节点，主张"流程即质量、质量即流程"。
 - **DCP（决策评审点，共 5 个）**：由 IPMT（集成组合管理团队）主导，关注商业可行性，决定是否继续投资。
 - **TR（技术评审点，TR1–TR6）**：由技术专家主导，关注技术可行性与质量，逐段拦截需求/架构/设计/代码/系统级缺陷；**实行一票否决制**——评审不通过不得进入下一阶段。
- **质量红线 / 零缺陷实践**：培育"一次把事情做对、零缺陷、持续改进、质量是自尊心"的质量文化，引导全员从"要我质量"转向"我要质量"；融合 ISO9000、六西格玛、零缺陷等理念。
- **质量优先于成本与进度的文化**：项目绩效中质量维度占比不低于三成，重大质量事故直接扣分、评优一票否决；"以标准为唯一依据，不妥协、不迁就、不降低标准"；数据显示上市后整改缺陷成本约为设计阶段 100 倍以上，故以事前预防降本、以硬指标"准出"守住质量底线。

### 代表工具 / 方法
- IPD 质量门（DCP / TR 评审）、FMEA、QFD、六西格玛改进、质量度量（缺陷密度/测试覆盖率）、质量回溯、PQA（产品质量保证）独立审计。

### 可借鉴点
- 把质量"内嵌流程"而非"事后检验"，用关口（质量门）把风险前移；
- 用"一票否决 + 质量绩效绑定"把质量底线制度化，而非口号；
- 以预防投入降低全生命周期综合成本，实现质量与商业成功的统一。

### 来源（公开资料）
- 《某通信科技龙头集成产品开发 IPD 质量管理体系详解》（安谋咨询，公开长文）。
- 某通信科技龙头"质量反思大会""以客户为中心、以质取胜""从零缺陷到大质量"等公开报道（车质网、深圳 bring、今日头条等，2024–2025）。
- 某通信科技龙头内训丛书《以客户为中心》《价值为纲》（黄卫伟 主编，中信出版社），参见 `books.md` #16/#17；任正非管理思想与质量高频词另见 `books.md` #18《某通信科技龙头管理之道》。

## 二、某汽车集团：并购某北欧豪华品牌后的质量体系跃升

### 核心做法
- **并购某北欧豪华品牌驱动体系升级**：2010 年收购某北欧豪华品牌，不仅获得资本意义上的豪华品牌，更实质性获得某北欧豪华品牌近百年积累的开发逻辑——"标准高于法规"的安全/质量基因。
- **全方位安全管理体系（GTSM）**：2008 年构建，将"安全/质量"从单一产品性能指标扩展为覆盖**研发、制造、供应链、售后全链条**的系统工程。
- **IATF16949 与全球标准话语权**：2021 年 4 月 8 日正式加入 IATF（国际汽车工作组），成为其**第 10 家汽车集团成员、史上首个亚洲成员**，拥有董事表决权；2023 年参与全球 IATF16949 标准改版，应对汽车"新四化"（电动/智能/网联/共享）。
- **全生命周期质量管理 + 对标豪华车**：以某北欧豪华品牌"最安全"豪华品牌开发逻辑为标杆，建立覆盖产品全寿命周期的质量管控，对标豪华车质量水平。

### 代表工具 / 方法
- IATF16949 / VDA6.3 体系、APQP 五大工具、供应商质量协同、GTSM 安全系统工程、全生命周期质量追溯。

### 可借鉴点
- 通过并购"借力"成熟体系，快速补齐开发与质量标准短板；
- 把安全/质量做成跨职能系统工程（而非质检部门职责）；
- 参与国际标准制定，从"跟随"转向"规则共建"。

### 来源（公开资料）
- 某汽车集团加入 IATF 一周年/获 IATF"杰出贡献奖"相关报道（网易、中华网、Geely 官方，2022–2023）。
- 某汽车集团"安全，久久为功""转型升级的密码""以质量创新引领行业高质量发展"等公开报道（搜狐、汽车评价研究院、中国质量新闻网，2019–2024）。
- 注：某汽车集团质量专著见 `books.md` #38《新制造时代：某汽车集团全球化制造》（王千马、梁冬梅，2017）；系统方法见 `quality-in-tools.md` 采购/生产制造场景。

## 三、航空宇航：双归零方法论与宇航质量体系

### 核心做法
- **航空宇航特色质量管理**：从"两弹一星"到"神舟""嫦娥"，中国航空宇航长期是质量管理的"试验田"，率先探索全面质量管理、ISO9000、产品保证、"零缺陷"等；在 1996 年多次发射失利后系统反思，形成**质量问题"双归零"**方法。
- **质量问题"双归零"（双五条）**：对研制/生产/试验/交付/服务中出现的质量问题，从技术与管理两方面闭环。
 - **技术归零五条**：**定位准确 → 机理清楚 → 问题复现 → 措施有效 → 举一反三**（归零"物"的问题）。
 - **管理归零五条**：**过程清楚 → 责任明确 → 措施落实 → 严肃处理 → 完善规章**（归零"人/流程"的问题）。
 - 关系：多数技术问题伴生管理不足；管理归零是技术归零的延续，在更深层面铲除重复发生根源；遵循 PDCA，按戴明/朱兰/克劳士比/费根堡姆共同的"质量改进"主题。
- **标准固化**：《航天产品质量问题归零实施要求》（Q/QJA10）、《航天产品质量问题归零实施指南》（QJ3183）等行业/集团标准；纳入单位质量管理体系并建立归零信息管理系统。
- **AS9100 航空宇航质量体系**：面向航空/航空宇航/国防的 ISO9001 增强版，强调安全、风险与产品保证。
- **NASA 质量文化（公开理念）**：以"故障即教材、每起事故都源于此前被忽视的信号"著称的失败学习文化，与"双归零"异曲同工，其制度化载体包括：① Lessons Learned Information System（LLIS）经验教训知识库，把单次故障转化为组织级预防资产；② Safety and Mission Assurance（SMA）独立技术权威，独立于项目、直接向局长/中心主任报告，纠偏"进度压倒安全"；③ 高可靠组织（HRO）五原则——对失败念念不忘、拒绝简化、对操作敏感、承诺韧性、尊重一线专业判断；④ 事故后制度重构（Challenger 1986 → 罗杰斯委员会；Columbia 2003 → CAIB 哥伦比亚事故调查委员会，强化独立监管与"上升通道"）。

### 代表工具 / 方法
- 双归零（双五条）、归零报告 + 分级评审（集团/院/厂所）、产品保证 PA、FMEA/FTA、FRACAS、AS9100、故障树/根本原因分析。

### 可借鉴点
- 用"双归零"把单次问题转化为组织级预防资产（对其他型号"防火"）；
- 技术上定位机理、管理上严肃追责并固化到规章，技术与管理的双闭环；
- "一把手"负责、行政正职担责，把质量定义为系统性"一把手工程"。

### 来源（公开资料）
- 《航空宇航质量问题双归零管理方法》（可靠性论坛/中国质量报，含技术归零五条、管理归零五条逐条释义）。
- 载人航空宇航"质量小词典""双想/归零"术语科普（中国载人航空宇航工程网、科普中国，2025）。
- AS9100 / 航空宇航产品保证相关公开标准解读（行业资料）。
- 注：航空宇航/航空质量专著见 `books.md` #37《归零——中国航天质量的核心方法》（李京苑 主编，2022）。

## 四、quality-in 工具地图

### 核心做法
- **平台定位**：quality-in 工具地图（运营主体：质上科技服务（北京）有限公司），中国专业的质量在线学习及交流平台，提供课程、企业咨询与行业白皮书/干货文章。
- **课程体系**：针对全价值链质量管理及环境、职业健康安全管理，**规划开发 17 个系列近 300+ 门专业课程**（平台宣传口径；早期对外宣传为"16 系列近 200+ 门"），覆盖研发到供应链，并针对不同行业拓展迭代；课程可公开培训或企业内训。
- **科学分层**：按学员职业发展层次对课程做系统分级，对应其质量工具"四层地图"——①基础统计工具 ②专项改进工具 ③体系管理工具 ④战略改进方法论。
- **质量工具地图定位**：将工具按"基础统计—专项改进—体系管理—战略改进"四层导航（详见 `quality-in-tools.md`），便于"零基础→实战→体系→战略"的渐进学习。

### 代表课程 / 工具
- 先期产品质量策划 APQP（第三版，2024）、控制计划 CP（第一版，2024）、IATF16949:2016 标准理解与解析、SPC 统计过程控制、FMEA 七步法（IDAA 模型）、PFMEA、新/旧 QC 七工具、产品审核、质量总监能力系列等。
- 路径模型：质量战略实践模型（OPLE）、教练式咨询（非培训堆叠）。

### 可借鉴点
- 用"四层工具地图 + 系列化课程"把零散质量工具体系化，降低学习门槛；
- 强调"理论（系统）与组织实践融合"的教练式咨询，而非课程堆叠；
- 覆盖全价值链，便于企业按岗位/场景选学。

### 来源（公开资料）
- quality-in 工具地图官网首页、线下服务/课程体系页、课程中心（公开页面，2024–2025 检索）。
- 注：平台"白皮书/文章"具体篇目以官网内容中心为准；四层工具地图归纳见本 Skill `quality-in-tools.md` 与 `methods.md`。

## 五、某精密制造龙头：精密制造全工艺链质量治理

### 核心画像（公开资料，跨源调研）
- **定位**：某精密制造龙头（消费电子功能件）：全球消费电子精密功能件供应商 NO.1、AI 终端硬件核心供应商，某消费电子龙头核心供应链（某消费电子龙头为第二大客户、贡献营收约两成）。
- **一站式能力**：精密功能件 / 结构件 / 模组全链条智能制造；工艺链 **模切 → 冲压 → CNC → 注塑 → 表面处理(喷涂/PVD/电镀/阳极氧化/镭雕) → 组装/模组 → 包装出货**。
- **组织机制**：为每个终端客户品牌配备 **CFT 客户焦点团队（Customer Focus Team）**，快速响应客户 VOC 与特殊要求。
- **新业务**：人形机器人（具身智能超级工厂，北京亦庄，规划 2030 年产能 50 万台套（企业规划口径））、新能源汽车与低空经济核心材料·功能件·模组、AI 终端硬件。
- **质量/智造底座**：工艺设计/模具开发/自动化集成/IE 精益化/大数据分析 深度耦合的"系统化智造体系"；"模块平台化"柔性能力与数据化工艺仿真，应对定制化小批量高频迭代。

### 代表工具 / 方法（映射到 QCM）
- 过程控制：SPC(##A01) + 控制计划(##B05) + MSA(##A05) + Poka-Yoke(##A02)（冲压划伤/毛刺、CNC 刀纹、注塑缩水逐序设防）；
- NPI：APQP(##B06) + DFMEA/PFMEA(##B01) + PPAP(##B03) + VDA6.3(##E01)，CFT 对接 EVT→DVT→PVT→MP 质量门（呼应 公开知识库《从 P1 到量产 NPI 流程》）；
- 表面处理外观：喷涂工序控制(公开知识库 专题) + SPC + FMEA；
- 供应商：PPAP + 供应商审核(##E02) + 记分卡(##E03) + SQE(##E05)；
- 售后闭环：8D(##F01) + FRACAS(##C08) + 双归零式客户特殊要求闭环；
- 公司级：方针管理(##C06) + TQM + COPQ(##C09)。

### 可借鉴点
- **工艺链逐序设防**：精密制造的质量风险高度分布在前工序（冲压划伤、CNC 碰伤），用 Poka-Yoke 源头防错 + SPC 过程受控比末端全检更经济；
- **CFT 把客户特殊要求前置为质量门**：某消费电子龙头/某通信科技龙头的 CSR 与质量协议经 CFT 转化为 APQP/PPAP 硬门，未过不得量产；
- **"模块平台化 + 数据化工艺仿真"要求质量前移**：公差分析（呼应 公开知识库《会做公差分析的人》）与 DOE 前置到工艺设计，支撑柔性高频迭代；
- **行业定制治理**：通用实战推演（去品牌化）详见本 Skill `references/workshop.md`（8 大高频车间/场景 × 20 工具应用 + 某精密制造龙头（消费电子功能件）/某射频器件龙头/某精密制造龙头（精密结构件）友商对标 + 通用 RACI + 治理节拍）。

### 来源（公开资料，三源）

- 2024 年度可持续发展报告（系统化智造体系）；港股 IPO 递表/招股书报道（CFT 机制，2026-06；截至 2026-07 为第三次递表，尚未完成上市）；深交所 ESG 实践案例集"双核驱动"；深圳质量协会质量改善奖项报道（"质能"升级/数字化质量）；

## 六、某精密制造龙头（消费电子 + 新能源双轮）的质量闭环

### 核心画像（公开资料，2026-07-22 跨源调研）
- **定位**：2001 年成立、2010 创业板上市，总部深圳；弗若斯特沙利文称其 2025 年按收入计为全球第五大智能终端及电子产品精密零组件制造商；2024 中国电子元件百强第 14 位；2024 营收 169.34 亿元，员工超 2.9 万。
- **三大板块**：智能终端零组件（消费电子）/ 新能源汽车零组件 / 智能制造装备及系统集成。
- **主要客户**：消费电子—某消费电子龙头（核心客户）、某消费电子龙头；新能源/汽车—某新能源车企（一级供应商，车身结构件、高压连接器、电池 Pack；Optimus 关节齿轮/轴承核心认证供应商）、某动力电池龙头（六大优秀供应商之一）、某新能源车企。
- **核心工艺链**：精密模具（±2μm，年产能 10000+ 套）→ 高速精密冲压、精密塑胶成型/注塑、CNC（金属中框/压铸/冲压/阳极/组装）、表面处理（阳极/镭雕/自动化打磨去毛刺）、自动化集成与组装；材料覆盖铝/不锈钢/钛/镁合金/PEEK。
- **质量/智造底座**：ISO9001:2015、IATF16949:2016、ISO14001、ISO45001、QC080000、某消费电子龙头 Supplier 行为准则；自研六轴工业机器人（重复定位 ±0.02mm、循环 0.35s）；IMS 平台"机内量测+大数据/AI 自动补偿工艺"。

### 代表工具 / 方法（映射到 QCM）
- 体系与治理：品质部具**独立地位 + 质量一票否决权**；明确使用 APQP(##B06) + 控制计划 + CTQ 关键工序识别 + SPC(##A01) 实时监测 + Cpk + 4M1E 现场管制 + 首/中/末三检 + 设备履历（预防性维护/TPM#14）+ CAPA 客户反馈闭环 + ERP 编码批次追溯。量化 KPI：客户满意度≥90、投诉解决率 100%、召回比例 0%。
- 过程防错：100+ 条自动化打磨去毛刺线（Poka-Yoke#2 自动化升级）、镭雕线 50+、检测线 50+、组装线 10+；机内量测+AI 自动补偿修正 CNC 尺寸漂移（MSA#7 数据化）。

## 十、软件行业质量管理（研发质量 / DevOps / MLOps）

> 软件质量 = 朱兰「适用性」在比特世界的延伸：不仅功能正确，还要可靠、安全、可演进。与制造质量同构的是「门禁前置」——把质量门嵌入研发流水线（类比 §一 通信科技 IPD 质量门），而非上线后救火。软件行业零命中于旧版 cases.md，本章为系统化增补；案例为公开 DevOps/MLOps 失效模式蒸馏 + 框架化，非特定企业复刻，来源公开资料。

### 8.1 某金融科技 SaaS 发布回滚危机（重度 D=7 · 软件研发 · 持续交付）

- **核心做法（行业基准）**：
  - **流水线质量门**：提交→构建→单元测试→集成测试→安全/依赖扫描→混沌演练→发布门禁，任一红则卡流（类比 IPD TR 技术评审一票否决）。
  - **金丝雀 + 一键回滚**：小流量灰度，核心指标（错误率/时延/资损）超阈即自动回滚，缩小爆炸半径。
  - **变更分级**：按影响面（客户资金/合规）定变更审批级别与冻结窗。
- **危机复盘（框架化）**：某次紧急修复为赶窗口**绕过快照回归测试**直接合入，触发资金计算偏差 + 客诉激增；事后以 **DMAIC（##F03）/ 8D（##F01）** 复盘，根因 = 门禁被人工豁免 + 缺乏强制回滚演练；措施 = 门禁不可豁免策略 + 回滚演练常态化 + 回归用例补全。
- **代表工具 / 方法（映射到 QCM）**：
  - 质量门 / 持续交付：对齐 ##F03 DMAIC 路线图 + ISO 9001 §8.5/§8.6（生产/交付放行）；
  - 回归补全：##G04 生成式测试设计（LLM 补边界用例，需求覆盖率 ≥95%）；
  - 失效闭环：##C08 FRACAS + ##F01 8D + CAPA（##F06）；
  - 过程能力：##A01 SPC 用于发布指标过程受控监控。
- **可借鉴点**：
  - 把「质量门」从文档要求变成流水线硬卡（不可豁免），是把质量前置的工程化落地；
  - 用金丝雀 + 自动回滚把「上线即赌博」转为「可控实验」，爆炸半径可控；
  - 回归用例随缺陷回流持续补全（类比 ##G09 质量知识图谱沉淀）。
- **来源（公开资料）**：DevOps / 持续交付通行实践（DORA 四项指标 · 部署频率/前置时长/变更失败率/恢复时长）；混沌工程原则（韧性验证）；某金融科技公开故障复盘范式。

### 8.2 某推荐 / 风控 MLOps 模型退化危机（重度 D=7 · MLOps · 模型质量）

- **核心做法（行业基准）**：
  - **模型监控**：漂移（数据/概念漂移）+ 性能（AUC/时延）+ 偏差（分组公平）在线监控，超阈告警（对齐 ##G10 上线监控）。
  - **再训练闭环**：影子 / AB 验证 → 再训练 → 模型卡登记 → 治理评审（对齐 ISO/IEC 42001 §8/§9 + NIST AI RMF Measure/Manage）。
  - **反馈循环防御**：防止模型输出反噬训练数据（自指退化）。
- **危机复盘（框架化）**：某推荐模型因用户行为分布漂移 + 反馈循环，推荐质量与转化在 3 周内骤降并引发偏差投诉；以 **##G06 LLM-RCA / 5Why（##F02）** 定位根因 = 监控只看准确率、未看分布漂移；措施 = 漂移告警（##G05）+ 预测性再训练（##G02）+ 偏差审计（##G10）+ 双归零闭环。
- **代表工具 / 方法（映射到 QCM）**：
  - 退化预测：##G02 预测性质量（RUL/拐点预测思路迁移到模型性能）；
  - 异常检测：##G05 无监督异常检测（多维监控信号）；
  - 根因：##G06 大模型辅助根因分析 + ##F02 5Why；
  - 治理：##G10 AI 治理与模型风控 + ISO/IEC 42001（见 §9）+ NIST AI RMF；
  - 数据：##G07 合成数据增强（长尾场景补数据）。
- **可借鉴点**：
  - 「模型上线 ≠ 质量完成」，须把质量门延伸到**模型全生命周期**（监控→再训练→评审）；
  - 单一准确率指标会掩盖分布漂移，质量度量须多维（性能/漂移/偏差/韧性）；
  - 软件/AI 质量与制造质量同构：围堵（回滚/降级）→ 消除（根因）→ 纠正（再训练/治理）→ 预防（监控闭环）。
- **来源（公开资料）**：MLOps / 模型风险管理通行实践（Google ML Test Score / 模型卡片范式）；ISO/IEC 42001:2023 + NIST AI RMF（见 standards.md §9）；某推荐系统退化公开复盘范式。
