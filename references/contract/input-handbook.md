## 5. 字段输入决策树

```
QCM 输入决策（基于 F11 紧迫度 + F24 危机等级 + 输出形态）
├─ 紧急 + 重度（P1）→ 4 形态：快速响应（④）
├─ 重要 + 中度（P2）→ 4 形态：决策卡片（②）
├─ 重要 + 普通（P3）→ 4 形态：案例应用（①）或 评估报告（③）
└─ 常规 + 微型（P4）→ 4 形态：评估报告（③·季度）
```
