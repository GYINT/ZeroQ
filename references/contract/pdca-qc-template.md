# PDCA + 5W1H + QC/CDA 活动流操作模板

> **定位**：基于 **PDCA 循环（计划-执行-检查-改进）** + **5W1H 计划工具** + **QC 活动（品管圈·现场改善）** + **CDA 活动（Confirm-Do-Act 持续改善）** 的中文可填写操作模板。
> **与 QCM 既有资产的关系**：QC 七工具见 `tools.md` A01–A08（SPC/柏拉图/鱼骨图/检查表/直方图/散布图/层别法）；PDCA 作为方法论总览见 `methods/methods.md`；危机管理 + 责任层见 `action-orders §3 + §5`。
> **触发词**：PDCA / 5W1H / QC活动 / CDA活动 / 推移图 / 雷达图 / 标准化（已落盘 `keyword.yaml`，intent ②流程优化）。
> **与 5W2H 区分**：5W1H 侧重"计划阶段工具"（②流程优化），5W2H 侧重"问题陈述/危机处置"（①危机处置），二者并存。

## 一、阶段总览

```
问题/任务 → PDCA循环 → 5W1H（计划工具）→ QC活动（品管圈）→ CDA活动（持续改善）
   │           │              │                  │                  │
   │     ┌─────┴─────┐    ┌──┴──┐            ┌──┴──┐            ┌──┴──┐
   ▼     │  Plan      │    │ What Why How When Who Where │     │ C(Confirm) D(Do) A(Action) │
     │  Do        │    └─────┘            │ 选题·现状分析·目标设定 │
     │  Check     │                       │ 对策实施·效果确认·标准化·发表 │
     │  Action    │
     └───────────┘
```

## 二、PDCA 四 阶段

### P · Plan（计划）—— 用 5W1H 拆解

| 5W1H | 含义 | 输出工具 | 在 QCM 的对应工具 |
|------|------|---------|------------------|
| **What（什么）** | 主题/对象是什么？现状与差距 | **检查表** / **管制图（控制图）** / **现况分析**（流程/柏拉图）| A08 检查表 / A01 SPC / A03 柏拉图 |
| **Why（为何）** | 为什么发生？根因在哪 | **要因分析**（**鱼骨图** 4M）| A03 鱼骨图 |
| **How（如何）** | 如何解决？对实施计划 | **对策实施**（**计划表**）| tools F01–F08 |
| **When（何时）** | 什么时间开始/结束？里程碑 | 时间表（甘特图）| `methods/process-flow.md` |
| **Who（谁）** | 谁负责？跨职能团队 RACI | 责任矩阵 | `action-orders §5` 责任层 |
| **Where（何处）** | 在哪个工序/工位/区域发生 | 工序地图 / 价值流图 | D05 VSM |

**Plan 阶段交付物**：5W1H 完整填写 + 现状差距陈述 + 根因鱼骨图 + 对策清单 + 责任矩阵 + 时间表。

### D · Do（执行）

| 工具 | 用途 |
|------|------|
| **执行改善方案** | 按 P 阶段确定的对策与计划落地 |
| **推移图** | 实时追踪关键指标的时间变化（每日/每周数据点） |

**Do 阶段交付物**：执行记录 + 推移图（指标随时间的变化曲线）。

### C · Check（检查）

| 工具 | 用途 |
|------|------|
| **效果确认** | 对策执行后指标是否达到 P 阶段目标 |
| **管制图（控制图）** | 验证过程是否稳定 / 异常点是否消失 |
| **雷达图** | 多维度指标综合评估（质量/成本/交付/安全/士气）|

**Check 阶段交付物**：效果确认报告 + 管制图/雷达图 + 与 P 阶段目标的对比结论。

### A · Action（改进）

| 动作 | 用途 |
|------|------|
| **标准化** | 将有效对策写入 SOP/PFMEA/CP/作业指导书 |
| **撰写成果报告书** | 一页式 A3/8D 格式记录全过程 |
| **成果发表** | 在部门/公司 QC 发表会横向推广 |

**Action 阶段交付物**：标准化文件更新 + 成果报告书 + QC 发表记录 + 横向推广计划。

## 三、QC 活动（品管圈 · QC Story）

QC 活动通常按以下 8 步组织（与 PDCA + 5W1H 高度同构）：

| 步骤 | 动作 | 对应 PDCA | 5W1H |
|------|------|----------|------|
| 1 | **选题**（自上而下/自下而上） | Plan | What |
| 2 | **现状分析**（柏拉图/流程图） | Plan | What |
| 3 | **对策研讨 + 计划设定目标** | Plan | Why/How/When/Who/Where |
| 4 | **对策实施**（小范围试作） | Do | How |
| 5 | **效果确认**（雷达图/管制图）| Check | What/Why |
| 6 | **标准化**（写 SOP/PFMEA）| Action | How |
| 7 | **撰写报告书** | Action | — |
| 8 | **发表会 + 后续追踪** | Action | — |

## 四、CDA 活动（Confirm-Do-Act · 持续改善）

> CDA 是 PDCA 的衍生强化版，强调**先确认（Confirm）再行动（Do）最后固化（Action）**，与 PDCA 区别在于 Plan 阶段弱化为"基于上轮 Check 结果的确认"。

| 步骤 | 动作 | 与 PDCA 对应 |
|------|------|-------------|
| **C · Confirm（确认）** | 回顾上一轮效果确认结果，确认本轮改善方向 | 复用上一轮 Check + Plan |
| **D · Do（执行）** | 按确认方向执行改善 | = PDCA Do |
| **A · Action（标准化）** | 固化有效对策 | = PDCA Action |

**适用场景**：已有 PDCA 基础（团队成熟）+ 课题持续滚动（无需重新选题）。

## 五、检查清单（最小可用交付物）

```
□ Plan：5W1H 六 问全部填写（含 What 数据基线）
□ Plan：鱼骨图至少 4M 维度展开
□ Do：推移图覆盖完整执行期（建议 ≥ 4 周数据点）
□ Check：效果确认有量化指标对比（基线 vs 改善后）
□ Check：管制图验证过程稳定性
□ Action：标准化文件已落地（SOP/PFMEA/CP 至少 1 项）
□ Action：成果报告书 + 发表记录
□ 与既有体系挂接：8D 报告（应对客户投诉/重大异常）/ 3A5WHY（根因三链）/ 四性评估（流出管控方案）
```
