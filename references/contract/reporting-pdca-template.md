# 业务报告 PDCA 机制模板（Reporting PDCA Template）

> **定位**：基于 **PDCA 四阶段 × 5W2H 指示确认 × 上级报告闭环**的业务报告机制中文可填写模板。核心目标：**确保问题解决、各流程顺利实施**。
> **与 QCM 既有资产的关系**：PDCA 骨架见 `methods/pdca-qc-framework.md`；5W2H 同族工具见 `keyword.yaml`（②流程优化）；危机沟通 3T 见 `action-orders §3.3`；报告-商谈-修改闭环 = 输出层 4 形态的沟通侧配套。
> **触发词**：业务报告 / 报告机制（已落盘 `keyword.yaml`，intent ②流程优化）。

---

## 一、机制总览

```
P·企划决策 ─→ D·业务终检 ─→ C·实施结果 ─→ A·改善
     │             │              │            │
     │  5W2H 确认指示 · 预约上级 · 企划案      │
     │             │  工作执行 · 预约 · 报告    │
     │             │              │  改善方案 · 报告书 · 商谈
     │             │              │            └─ 标准化（业务手册）
     └────────── 报告 → 商谈 → 修改 → 再报告（每阶段闭环）──────────┘
```

**沟通主线**：就**企划、进展情况、结果和改善方案**与上级进行沟通（报告-商谈-修改闭环）。

**5W2H 应用**：P 阶段用 5W2H 确认指示内容（What 做什么 / Why 目的 / How 怎么做 / When 何时 / Who 谁 / Where 何处 / How much 量化目标）。

---

## 二、P 阶段 · 企划决策报告（Plan）

| # | 动作 | 5W2H 要素 | 交付物 |
|---|------|----------|--------|
| 1 | **接受指示** | What/Why | 指示记录 |
| 2 | **根据 5W2H 确认指示的内容** | What/Why/How/When/Who/Where/How much | 5W2H 确认表 |
| 3 | **确定决策的日期** | When | 决策日程 |
| 4 | **预约上级的时间** | When/Who | 会议预约 |
| 5 | **按报告时间制作企划案** | How | 企划案 |
| 6 | **报告（商谈）** | — | 商谈纪要 |
| 7 | **按照指示进行报告** | — | 修订企划案 |
| 8 | **修改后再次报告** | — | 定稿企划案 |
| 9 | **根据业务日程推进工作** | When | 实施日程表 |

---

## 三、D 阶段 · 业务终检报告（Do）

| # | 动作 | 交付物 |
|---|------|--------|
| 1 | **工作**（按 P 阶段批准方案执行）| 执行记录 |
| 2 | **预约上级时间** | 会议预约 |
| 3 | **报告**（进展/结果）| 进展报告 |
| 4 | **按指示进行修改** | 修订记录 |

**紧急联络**：进展与计划不符或情况恶化时，**立即紧急联络**上级（不等定期报告节点）。

---

## 四、C/A 阶段 · 实施结果 + 改善报告（Check / Act）

| # | 动作 | 交付物 |
|---|------|--------|
| 1 | **预约上级时间** | 会议预约 |
| 2 | **按报告时间制作具体改善方案** | 改善方案 |
| 3 | **汇总实施结果、改善方向制作报告书** | 报告书 |
| 4 | **报告（商谈）** | 商谈纪要 |
| 5 | **按照指示进行修改** | 修订记录 |
| 6 | **改善（制作手册）** | 业务手册 |
| 7 | **标准化的业务报告** | 标准化模板 |
| 8 | **进入 C、A 阶段**（下一轮 PDCA 循环起点）| 下一轮计划 |

---

## 五、检查清单（最小可用交付物）

```
□ P 阶段：5W2H 确认表完整（7 要素全填）
□ P 阶段：企划案经报告-商谈-修改闭环（≥1 轮）
□ D 阶段：执行记录 + 进展报告 + 按指示修改
□ D 阶段：异常/恶化时紧急联络（24h 内）
□ C/A 阶段：报告书含实施结果 + 改善方向
□ C/A 阶段：改善方案 + 业务手册标准化
□ 全程：预约-报告-商谈-修改闭环可追溯
□ 与 PDCA 四阶段对齐（P/D/C/A 均有报告记录）
```
