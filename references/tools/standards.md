### 9.2 ISO/IEC 42001:2023 条款映射（Annex SL 结构）

- **概述**：首个 AI 管理体系国际标准（2023-12 发布），采用 Annex SL 高阶结构，与 ISO 9001:2015 同构（PDCA + 过程方法），便于与既有 QMS 一体化审计。
- **条款 → QCM 治理对齐**：

| 条款 | 主题 | 与 QCM 治理对齐 |
|------|------|------|
| 4 组织环境 | 内外部议题 / 相关方 / 适用范围 | 对齐 `governance.md` 组织治理 RACI + 相关方清单 |
| 5 领导作用 | AI 政策 / 角色职责 / 治理承诺 | 对齐公司级质量治理「一把手工程」+ 独立质量地位 |
| 6 策划 | AI 风险与机遇 / 目标 | 对齐 ISO 31000 风险框架 + 质量目标 |
| 7 支持 | 资源 / 胜任力 / 意识 / 沟通 | 对齐 SQE / 数据治理组织保障 |
| 8 运行 | AI 系统生命周期过程控制 | 对齐 ##G10 模型风控 + MLOps/DevOps 过程 |
| 9 绩效评价 | 监测 / 审计 / 管理评审 | 对齐 ##G10 上线监控 + 治理评审 |

- **Annex A 专项控制项**（已实证：共 **38 项控制**，分 **9 类 A.2–A.10** —— A.2 政策(2) / A.3 内部组织(3) / A.4 资源(5) / A.5 影响评估(5) / A.6 生命周期(6) / A.7 数据(4) / A.8 相关方信息(5) / A.9 系统使用(4) / A.10 第三方关系(4)；组织按风险裁剪，记入适用性声明 SoA）。

### 9.3 NIST AI RMF 四核心函数 + 可信 AI 特性

- **四核心函数**（AI RMF 1.0，2023-01 发布，自愿性框架）：
  - **Govern（治理）**：跨组织建立 AI 风险治理文化、政策与问责——对应 ISO 42001 条款 5。
  - **Map（映射）**：识别 AI 系统场景 / 风险 / 影响——对应条款 4 / 6。
  - **Measure（度量）**：以定量 / 定性方法评估风险与可信属性——对应条款 9。
  - **Manage（管理）**：按风险优先级处置并持续监控——对应条款 8 / 10。
- **可信 AI 七特性**：Valid and Reliable（有效可靠）· Safe（安全）· Secure and Resilient（安全韧性与抗对抗）· Accountable and Transparent（可问责透明）· Explainable（可解释）· Privacy-Enhanced（隐私增强）· Fair with Harmful Bias Managed（公平且有害偏差受控）。
- **衍生**：NIST AI 600-1《GenAI Profile》(2024-07) 面向生成式 AI 独有价值与风险，是 RMF 的专项扩展。

### 9.5 双标准协同与落地建议

- **ISO 42001 = 管理体系（可认证）**：提供 PDCA 结构化骨架，便于与 ISO 9001 QMS 一体化审计。
- **NIST AI RMF = 风险框架（可评估）**：提供 Govern/Map/Measure/Manage 四函数与可信特性清单，适合做差距评估与选型。
- 二者互补、均以 Annex SL / 风险导向为基调；建议「ISO 42001 建体系 + NIST AI RMF 做评估 + ISO 27001 补信息安全 + EU AI Act 补合规」组合落地（见 §4 当代 + AI 行）。
- **QCM 接合点**：把 AI 治理纳入既有质量治理双归零闭环——技术归零（模型 / 数据根因）+ 管理归零（治理职责 / 流程），与 AI 大师「可信 AI / 数据centric」主张一致。

### 10.2 ISO GPS 体系关系
- ISO 1101（几何公差）· ISO 8015（基本原则/独立原则）· ISO 5459（基准系统）· ISO 286（极限与配合，即 GB/T 1800）共同构成 **GPS 体系**。
- ASME Y14.5 与 ISO 1101 **同宗但默认原则对立**：包容（ASME）vs 独立（ISO）；跨境图纸须显式标注单一标准，禁止混用约定。

### 10.3 与 ##D26 对齐
- 公差分析"极值法/概率法选择""Cp/Cpk 判据"落地为图纸标注时，须引用上述标准；**非对称公差转对称**（六步法第 3 步）是 GPS/ASME 通用前置。
- 异型材压延厚差治理（规格示例 `X.XX+0.0X-0.0X`）的尺寸链建模与公差分配，应挂钩 **GB/T 1800.1-2020（极限与配合）** + **ISO 1101:2017 / GB/T 1182-2018（几何公差）**。

### 10.4 来源实证（外网核验 · 2026-08-31）
- ASME 官网 Y14.5-2018 (R2024)；ISO 1101:2017（BS EN ISO 1101:2017）；GB/T 1800.1-2020 / GB/T 1182-2018（gbstandards.org · 等效 ISO 286-1 / ISO 1101）。
- **口径修正**：规划/评估中"ISO GPS 1101"实为 **ISO 1101:2017**（GPS 为体系名，非标准号一部分）。
- 跨源一致（ASME 官网 / ISO 派生 / 国标库 / 多技术博文），**矛盾 0 处**；标准实体已注册（§9.1 列 1 抽取）。
