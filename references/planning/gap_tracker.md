## 调研流程（V8.0+ §13 协议实施）

### 阶段 1：缺口识别（自动·每次新场景触发）
- 输入：T-L 链路运行后产生的 5 维缺口
- 工具：QCM 决策引擎 + 缺口评分函数
- 产出：gap_tracker.md 表格新增/更新

### 阶段 2：自动浅层调研（自动·缺口分 ≥2）
- 工具：Infoseek auto-layer（无 LLM 介入）
- 范围：单源抓取 + 关键词命中
- 阈值：置信度 ≥70 → 主库；40-69 → 归因历史；<40 → 终止
- 耗时：~5 分钟

### 阶段 3：关键中层调研（自动·缺口分 ≥3）
- 工具：Infoseek LLM 层（按需调用）
- 范围：多源交叉 + 概念校验
- 产出：候选章节草稿 + 候选工具/标准列表
- 耗时：~30 分钟

### 阶段 4：用户深层调研（手动·缺口分 ≥4 + 用户确认）
- 工具：Infoseek 完整 research()
- 范围：6 维分桶（方法论/核心观点/语言风格/反共识/决策史/人格底色）
- 产出：完整章节 + 新工具/标准入主库
- 耗时：~2-3 小时
