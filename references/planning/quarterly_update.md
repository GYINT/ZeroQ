# QCM V8.0+ 季度更新模板（Quarterly Update）

> **协议层 SOLE 权威**：`action-orders.md` §13 缺口暴露驱动 Infoseek 协同协议
> **频率**：季度（Q1/Q2/Q3/Q4）
> **目的**：缺口暴露驱动 + 持续迭代 + 健康指标监控
> **核心原则**：缺口评分 ≥3 触发 Infoseek 调研；置信度分层入库

---

## 季度更新 4 阶段流程

### 阶段 1：缺口扫描（自动·每季第 1 周）
- 工具：gap_tracker.md 状态机更新
- 输入：上一季度 T-L 链路运行数据 + 新场景触发
- 产出：5 维缺口表 + 综合评分

### 阶段 2：调研启动（自动·每季第 1-2 周）
- 触发条件：缺口分 ≥3
- 工具：Infoseek 协同（自动浅层 + 关键中层）
- 输出：候选章节/工具/标准草稿
- 阈值：置信度 ≥70 → 主库；40-69 → 归因历史；<40 → 终止

### 阶段 3：写入与归档（人工·每季第 3 周）
- 工具：tools-classification.md / standards.md / cases.md / masters.md
- 双源同步：/sandbox/ + /root/
- 增量入测试：test-cases.md 新增组用例
- Manifest 双绑验证

### 阶段 4：健康指标报告（自动·每季第 4 周）
- 新鲜度（人物/方法论/工具当代占比）
- 行业覆盖（V8.0+ 计划 8 行业）
- 缺口暴露率/闭合率/入库率/学习率
- 输出：quarterly_health_report_YYYYQN.md

## 季度更新检查清单

### 缺口扫描维度
- [ ] 行业覆盖（8 行业：汽车/电子/航空/医疗/软件/金融/能源/食品）
- [ ] 工艺覆盖（10+ 工艺：冲压/CNC/注塑/焊接/喷涂/装配/检验/物流/仓储/包装）
- [ ] 工具覆盖（A-F 域 87 工具 + 新工具 G 域）
- [ ] 标准覆盖（ISO/IATF/AS/VDA/CQI/HACCP/GMP/ESG/AI）
- [ ] 大师覆盖（21 核心 + 当代 + 中国本土 + AI/数据）

### 新鲜度检查
- [ ] 工具当代占比（>80% 为 2020+ 主流）
- [ ] 标准版本时效（ISO 9001:2015 现行 / ISO 42001:2023 新标）
- [ ] 大师当代性（1940-2020 跨度是否覆盖）
- [ ] AI 工具占比（目标 ≥10%）

### 缺口评分标准
- 0 = 完全覆盖（已落格 + 有案例）
- 1 = 基本覆盖（已提及但未展开）
- 2 = 部分覆盖（有零星内容但无系统章节）
- 3 = 显著缺口（需启动调研）
- 4 = 主要缺口（优先调研）
- 5 = 关键缺口（必须立即调研）

### 调研方式
- **自动浅层**（缺口分 2-3）：Infoseek auto-layer，~5 分钟
- **关键中层**（缺口分 3-4）：Infoseek LLM 层 + 多源交叉，~30 分钟
- **用户深层**（缺口分 4-5 + 用户确认）：Infoseek research() 完整 6 维，~2-3 小时
