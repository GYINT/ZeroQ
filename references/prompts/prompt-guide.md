## 三、使用三原则（避免踩坑）

1. **写全三要素** Who + Where + What → Skill 精准路由，不场景错配。
2. **标深度** 单工具（要步骤）/ 组合（多工具解题）/ 系统级（搭体系）。
3. **带数据** 凡主张带数据（如"不良率 12%→≤1%"），无数据不决策（戴明）。

> 简化 prompt 填空公式：`[我的角色] + [价值链/工艺场景] + [具体问题/目标] + [要什么交付] + [深度]`。例：`我是PE + 冲压 + 毛刺复发 + 给4M根因展开表+防错方案 + 组合级` → 自动路由到 `workshop §1` + `tools-examples Poka-Yoke`。

## 四、T 层映射机制（深度 → 输出模板定位）

### 4.1 映射规则（三层）

```python
# 规则1：深度为主（Prompt 深度 → T 层基准）
单工具/单模块 → T2          # 要步骤，标准层
组合（多工具解题）→ T3      # 深度层
系统级（搭体系）→ T4        # 专家/治理层

# 规则2：场景修正（命中修正条件则上调）
+ 复发/客诉/三链 → T3       # 触发决策-L2⑥（如 B2 8D）
+ 组织级/战略/体系 → T4     # 触发决策-L4（如 D1/D2）
+ 纯知识查询/书单 → 无 T 层  # 不产生结构化输出（如 D5）

# 规则3：范围标注（非单值）
输出 [T2-T3] 而非 [T2]     # 允许跨层，防错配
```

### 4.2 触发词探测（深度未标注时 · 最多 1 轮）

```
触发: Prompt 未标深度（无"单工具/组合/系统级"字样）
探测: 系统主动问 1 轮:
  "这是首次发生还是复发？(首次/第二次及以上)
   只要方法步骤还是完整方案？(步骤/方案/体系)"
判定:
  首次 + 步骤     → T2
  首次 + 方案     → T3
  复发 + 任一     → T3（触发决策-L2⑥）
  体系/组织级     → T4
```

### 4.3 输出合成（双路由并行）

```
用户 Prompt
   ├─▶ 原路由 → 内容资产(people/tools/workshop/gk) → 交付内容
   └─▶ T层映射 → input-guide T1-T4 模板 → 结构化输出
                → output-templates L1-L4 格式
输出 = 内容资产交付 + 结构化分层输出（导航头/范式/穿透/治理）
```
