## 一、某通信科技龙头：以客户为中心的大质量体系

### 核心做法
- **以客户为中心**：视质量为企业的生命线，质量即"满足并超越客户需求"；"质量优先、以质取胜"为质量方针，目标是建立覆盖全流程、全价值链的"大质量"体系。
- **IPD（集成产品开发）中的质量门**：将质量要求深度内嵌于 IPD 六个阶段、5 个 DCP、6 个 TR 的每个节点，主张"流程即质量、质量即流程"。
 - **DCP（决策评审点，共 5 个）**：由 IPMT（集成组合管理团队）主导，关注商业可行性，决定是否继续投资。
 - **TR（技术评审点，TR1–TR6）**：由技术专家主导，关注技术可行性与质量，逐段拦截需求/架构/设计/代码/系统级缺陷；**实行一票否决制**——评审不通过不得进入下一阶段。
- **质量红线 / 零缺陷实践**：培育"一次把事情做对、零缺陷、持续改进、质量是自尊心"的质量文化，引导全员从"要我质量"转向"我要质量"；融合 ISO9000、六西格玛、零缺陷等理念。
- **质量优先于成本与进度的文化**：项目绩效中质量维度占比不低于三成，重大质量事故直接扣分、评优一票否决；"以标准为唯一依据，不妥协、不迁就、不降低标准"；数据显示上市后整改缺陷成本约为设计阶段 100 倍以上，故以事前预防降本、以硬指标"准出"守住质量底线。

### 代表工具 / 方法
- IPD 质量门（DCP / TR 评审）、FMEA、QFD、六西格玛改进、质量度量（缺陷密度/测试覆盖率）、质量回溯、PQA（产品质量保证）独立审计。

### 可借鉴点
- 把质量"内嵌流程"而非"事后检验"，用关口（质量门）把风险前移；
- 用"一票否决 + 质量绩效绑定"把质量底线制度化，而非口号；
- 以预防投入降低全生命周期综合成本，实现质量与商业成功的统一。

### 来源（公开资料）
- 《某通信科技龙头集成产品开发 IPD 质量管理体系详解》（安谋咨询，公开长文）。
- 某通信科技龙头"质量反思大会""以客户为中心、以质取胜""从零缺陷到大质量"等公开报道（车质网、深圳 bring、今日头条等，2024–2025）。
- 某通信科技龙头内训丛书《以客户为中心》《价值为纲》（黄卫伟 主编，中信出版社），参见 `knowledge-base.md` 书单#16/书单#17；任正非管理思想与质量高频词另见 `knowledge-base.md` 书单#18《某通信科技龙头管理之道》。

## 二、某汽车集团：并购某北欧豪华品牌后的质量体系跃升

### 核心做法
- **并购某北欧豪华品牌驱动体系升级**：2010 年收购某北欧豪华品牌，不仅获得资本意义上的豪华品牌，更实质性获得某北欧豪华品牌近百年积累的开发逻辑——"标准高于法规"的安全/质量基因。
- **全方位安全管理体系（GTSM）**：2008 年构建，将"安全/质量"从单一产品性能指标扩展为覆盖**研发、制造、供应链、售后全链条**的系统工程。
- **IATF16949 与全球标准话语权**：2021 年 4 月 8 日正式加入 IATF（国际汽车工作组），成为其**第 10 家汽车集团成员、史上首个亚洲成员**，拥有董事表决权；2023 年参与全球 IATF16949 标准改版，应对汽车"新四化"（电动/智能/网联/共享）。
- **全生命周期质量管理 + 对标豪华车**：以某北欧豪华品牌"最安全"豪华品牌开发逻辑为标杆，建立覆盖产品全寿命周期的质量管控，对标豪华车质量水平。

### 代表工具 / 方法
- IATF16949 / VDA6.3 体系、APQP 五大工具、供应商质量协同、GTSM 安全系统工程、全生命周期质量追溯。

### 可借鉴点
- 通过并购"借力"成熟体系，快速补齐开发与质量标准短板；
- 把安全/质量做成跨职能系统工程（而非质检部门职责）；
- 参与国际标准制定，从"跟随"转向"规则共建"。

### 来源（公开资料）
- 某汽车集团加入 IATF 一周年/获 IATF"杰出贡献奖"相关报道（网易、中华网、Geely 官方，2022–2023）。
- 某汽车集团"安全，久久为功""转型升级的密码""以质量创新引领行业高质量发展"等公开报道（搜狐、汽车评价研究院、中国质量新闻网，2019–2024）。
- 注：某汽车集团质量专著见 `knowledge-base.md` 书单#38《新制造时代：某汽车集团全球化制造》（王千马、梁冬梅，2017）；系统方法见 `knowledge-base.md` 采购/生产制造场景。

## 三、航空宇航：双归零方法论与宇航质量体系

### 核心做法
- **航空宇航特色质量管理**：从"两弹一星"到"神舟""嫦娥"，中国航空宇航长期是质量管理的"试验田"，率先探索全面质量管理、ISO9000、产品保证、"零缺陷"等；在 1996 年多次发射失利后系统反思，形成**质量问题"双归零"**方法。
- **质量问题"双归零"（双五条）**：对研制/生产/试验/交付/服务中出现的质量问题，从技术与管理两方面闭环。
 - **技术归零五条**：**定位准确 → 机理清楚 → 问题复现 → 措施有效 → 举一反三**（归零"物"的问题）。
 - **管理归零五条**：**过程清楚 → 责任明确 → 措施落实 → 严肃处理 → 完善规章**（归零"人/流程"的问题）。
 - 关系：多数技术问题伴生管理不足；管理归零是技术归零的延续，在更深层面铲除重复发生根源；遵循 PDCA，按戴明/朱兰/克劳士比/费根堡姆共同的"质量改进"主题。
- **标准固化**：《航空宇航产品质量问题归零实施要求》（Q/QJA10）、《航空宇航产品质量问题归零实施指南》（QJ3183）等行业/集团标准；纳入单位质量管理体系并建立归零信息管理系统。
- **AS9100 航空宇航质量体系**：面向航空/航空宇航/国防的 ISO9001 增强版，强调安全、风险与产品保证。
- **NASA 质量文化（公开理念）**：以"故障即教材、每起事故都源于此前被忽视的信号"著称的失败学习文化，与"双归零"异曲同工，其制度化载体包括：① Lessons Learned Information System（LLIS）经验教训知识库，把单次故障转化为组织级预防资产；② Safety and Mission Assurance（SMA）独立技术权威，独立于项目、直接向局长/中心主任报告，纠偏"进度压倒安全"；③ 高可靠组织（HRO）五原则——对失败念念不忘、拒绝简化、对操作敏感、承诺韧性、尊重一线专业判断；④ 事故后制度重构（Challenger 1986 → 罗杰斯委员会；Columbia 2003 → CAIB 哥伦比亚事故调查委员会，强化独立监管与"上升通道"）。

### 代表工具 / 方法
- 双归零（双五条）、归零报告 + 分级评审（集团/院/厂所）、产品保证 PA、FMEA/FTA、FRACAS、AS9100、故障树/根本原因分析。

### 可借鉴点
- 用"双归零"把单次问题转化为组织级预防资产（对其他型号"防火"）；
- 技术上定位机理、管理上严肃追责并固化到规章，技术与管理的双闭环；
- "一把手"负责、行政正职担责，把质量定义为系统性"一把手工程"。

### 来源（公开资料）
- 《航空宇航质量问题双归零管理方法》（可靠性论坛/中国质量报，含技术归零五条、管理归零五条逐条释义）。
- 载人航空宇航"质量小词典""双想/归零"术语科普（中国载人航空宇航工程网、科普中国，2025）。
- AS9100 / 航空宇航产品保证相关公开标准解读（行业资料）。
- 注：航空宇航/航空质量专著见 `knowledge-base.md` 书单#37《归零——中国航空宇航质量的核心方法》（李京苑 主编，2022）。

## 四、quality-in 工具地图

### 核心做法
- **平台定位**：quality-in 工具地图（运营主体：），中国专业的质量在线学习及交流平台，提供课程、企业咨询与行业白皮书/干货文章。
- **课程体系**：针对全价值链质量管理及环境、职业健康安全管理，**规划开发 17 个系列近 300+ 门专业课程**（早期对外宣传为"16 系列近 200+ 门"），覆盖研发到供应链，并针对不同行业拓展迭代；课程可公开培训或企业内训。
- **科学分层**：按学员职业发展层次对课程做系统分级，对应其质量工具"四层地图"——①基础统计工具 ②专项改进工具 ③体系管理工具 ④战略改进方法论。
- **质量工具地图定位**：将工具按"基础统计—专项改进—体系管理—战略改进"四层导航（详见 `knowledge-base.md`），便于"零基础→实战→体系→战略"的渐进学习。

### 代表课程 / 工具
- 先期产品质量策划 APQP（第三版，2024）、控制计划 CP（第一版，2024）、IATF16949:2016 标准理解与解析、SPC 统计过程控制、FMEA 七步法（IDAA 模型）、PFMEA、新/旧 QC 七工具、产品审核、质量总监能力系列等。
- 路径模型：质量战略实践模型（OPLE）、教练式咨询（非培训堆叠）。

### 可借鉴点
- 用"四层工具地图 + 系列化课程"把零散质量工具体系化，降低学习门槛；
- 强调"理论（系统）与组织实践融合"的教练式咨询，而非课程堆叠；
- 覆盖全价值链，便于企业按岗位/场景选学。

### 来源（公开资料）

## 五、某精密制造龙头：精密制造全工艺链质量治理

### 核心画像（公开资料，跨源调研）
- **定位**：某精密制造龙头（消费电子功能件）：全球消费电子精密功能件供应商 NO.1、AI 终端硬件核心供应商，某消费电子龙头核心供应链（某消费电子龙头为第二大客户、贡献营收约两成）。
- **一站式能力**：精密功能件 / 结构件 / 模组全链条智能制造；工艺链 **模切 → 冲压 → CNC → 注塑 → 表面处理(喷涂/PVD/电镀/阳极氧化/镭雕) → 组装/模组 → 包装出货**。
- **组织机制**：为每个终端客户品牌配备 **CFT 客户焦点团队（Customer Focus Team）**，快速响应客户 VOC 与特殊要求。
- **新业务**：人形机器人（具身智能超级工厂，北京亦庄，规划 2030 年产能 50 万台套）、新能源汽车与低空经济核心材料·功能件·模组、AI 终端硬件。
- **质量/智造底座**：工艺设计/模具开发/自动化集成/IE 精益化/大数据分析 深度耦合的"系统化智造体系"；"模块平台化"柔性能力与数据化工艺仿真，应对定制化小批量高频迭代。

### 代表工具 / 方法（映射到 QCM）
- 过程控制：SPC(##A01) + 控制计划(##B05) + MSA(##A05) + Poka-Yoke(##A02)（冲压划伤/毛刺、CNC 刀纹、注塑缩水逐序设防）；
- NPI：APQP(##B06) + DFMEA/PFMEA(##B01) + PPAP(##B03) + VDA6.3(##E01)，CFT 对接 EVT→DVT→PVT→MP 质量门（呼应 公开知识库《从 P1 到量产 NPI 流程》）；
- 表面处理外观：喷涂工序控制(公开知识库 专题) + SPC + FMEA；
- 供应商：PPAP(##B03) + 供应商审核(##E02) + 记分卡(##E03) + SQE(##E05)；
- 售后闭环：8D(##F01) + FRACAS(##C08) + 双归零式客户特殊要求闭环；
- 公司级：方针管理(##C06) + TQM + COPQ(##C09)。

### 可借鉴点
- **工艺链逐序设防**：精密制造的质量风险高度分布在前工序（冲压划伤、CNC 碰伤），用 Poka-Yoke 源头防错 + SPC 过程受控比末端全检更经济；
- **CFT 把客户特殊要求前置为质量门**：某消费电子龙头/某通信科技龙头的 CSR 与质量协议经 CFT 转化为 APQP/PPAP 硬门，未过不得量产；
- **"模块平台化 + 数据化工艺仿真"要求质量前移**：公差分析（呼应 公开知识库《会做公差分析的人》）与 DOE 前置到工艺设计，支撑柔性高频迭代；
- **行业定制治理**：通用实战推演（去品牌化）详见 `scenarios.md`（8 大高频车间/场景 × 20 工具应用 + 某精密制造龙头（消费电子功能件）/某射频器件龙头/某精密制造龙头（精密结构件）友商对标 + 通用 RACI + 治理节拍）。

## 六、某精密制造龙头（消费电子 + 新能源双轮）的质量闭环

## 八、某激光装备集团：质量体系规划与方针管理实践

### 核心做法
- **集团质量规划六模块**：质量管理系统规划（ISO 文件支撑体系+质量管理活动+流程与指标体系+组织保证与 IT 支撑）→ 质量管理组织架构（QM 质量策划/QA 评价改进/QS 体系/SQE/PQE/IQC/FQC/PQC/OQC）→ 质量管理运行机制（监督稽核 1 次/月·中心 + 管理评审/内审/品质稽核三层评价 + QRQC 快速反应/三现主义/班内完结 + PDCA 持续改进）→ 质量管理过程控制（设计开发 DQA/PQA/PQE、项目、客户服务、关键质量过程控制）→ 质量管理人员培育（十岗位×20+ 课程培训矩阵，★精通☆熟练●掌握〇了解）→ 中长期质量计划。
- **量化质量目标**：进料检验合格率≥98%、来料检验漏检率≤0.5%、客户服务满意率≥90%、成品检验合格率≥95%、进料检验验证率≥70%。
- **品质保证体系图**：APQP 式 5 阶段门控（计划项目确定→产品过程设计开发→产品和过程确认→量产前确认含 CPK 门控→反馈评定纠正），跨部门泳道 + NG/OK 门控。
- **品质保证监查评价**：5 级水平评价（来料检验 0.4/过程检验 0.2/技能培训 0.2/信息传递 0.1/改善推进 0.1 加权），达成率+查/问/现/证四法。
- **不符合分析 QR-QA-65**：发生→现状把握→解析→对策 4 阶段 18 步检查单（A-R），变化点量化/n 次确认/公差累加等判据。

### 代表工具 / 方法
方针管理（三级纵向展开+结果/要因双系指标）、X-Matrix 类目标矩阵、QRQC、品质保证监查 5 级评价、APQP 式 5 阶段门控、8D 细化（QR-QA-65 18 步）。

### 可借鉴点
- 质量目标全部量化且含"漏检率/验证率"类过程指标（不只结果指标）；
- 监督稽核频次明确（1 次/月·中心），介于内审与日常监控之间；
- 人员培育用"岗位×课程×熟练度"三维矩阵，可落地可考核；
- 品质评价用加权评分（来料 0.4 权重最高），聚焦进货质量源头。

## 一、战略层面（Strategic）：质量作为经营 / 系统战略

**定义**：战略层面把质量从"事后检验"提升到"经营决策"层，以系统观统筹顾客价值、质量成本与竞争力，使质量成为企业顶层战略语言而非质检部门职能。它回答"质量在企业里到底处在什么位置、由谁对质量负责"这一根本问题。

**代表人物**
- #02 戴明：深刻知识系统 + 14 点，以系统观重塑经营哲学，TQM 思想源头——战略层面的"系统变革"角色。
- #03 朱兰：适用性（Fitness for Use）定义质量 + 质量三部曲，把质量从车间提升到董事会——战略层面的"管理框架"角色。
- #04 克劳士比：零缺陷 + 质量免费，以 PONC/COPQ 把质量翻译成财务语言——战略层面的"质量成本范式"角色。
- #07 费根堡姆：首次命名 TQM，以质量成本整合全员质量经营——战略层面的"全面质量经营"角色。
- #20 久米均：质量经营（MBQ），以质量统筹企业经营战略与顾客价值——战略层面的"质量经营"角色。
- #21 德鲁克：目标管理 MBO + 自我控制 + 有效性，以"目标—衡量—责任"框架把质量目标逐级展开（方针管理 Hoshin 的理论源头）——战略层面的"目标治理骨架"角色。
- #14 泰勒：科学管理，标准化与可互换零件，为"质量为可重复性"奠定最早工程基础——战略层面的"标准化 / 可重复制造"角色。
- #17 福特：大规模生产与标准化，把质量锚定为可重复的稳定一致——战略层面的"规模化一致质量"角色。
- #18 哈默：BPR 业务流程重组，以结构性再设计阶跃式提升质量 / 成本 / 速度——战略层面的"流程战略重构"角色。
- #19 哈林顿：BPM/BPI，以过程管理统一质量改进与业务流程重组——战略层面的"过程管理粘合"角色。

**代表著作**
- #2 转危为安（Out of the Crisis，戴明 14 点与系统变革）

- #1 朱兰质量手册（Juran's Quality Handbook，朱兰，TQM 集大成）
- #18 某通信科技龙头管理之道（任正非质量高频词：大质量体系 / 质量优先 / 七个反对）
- #17 价值为纲（某通信科技龙头，质量与效益统一，财经支撑可持续经营）

- #11 零缺陷（Quality Without Tears，克劳士比，质量作为管理政策）

**代表案例**
- 某通信科技龙头：以客户为中心的大质量体系、"质量优先、以质取胜"方针，把质量定义为"企业活命的根本"，质量内嵌全流程全价值链、质量绩效一票否决——战略定调的标杆。
- 日本 TQM（久米均）：以质量经营统筹企业，顶层承诺 + 全员参与的企业级 TQM 日常体系，质量即经营。

## 二、过程层面（Process）：过程 / 系统设计与管理

**定义**：过程层面聚焦产品与服务的"过程本身"如何被设计、控制与优化，在研发与生产链路中把变异、浪费与失效风险前置到源头，使过程稳定且稳健。它回答"质量是如何被设计进流程、又如何在流程中被守住"的问题。

**代表人物**
- #01 休哈特：SQC 之父，控制图区分普通 / 特殊原因变异——过程层面的"统计过程控制"角色。
- #06 田口：稳健设计 + 质量损失函数，设计即质量——过程层面的"稳健参数设计"角色。
- #08 大野耐一：TPS，JIT + 自働化彻底消除浪费——过程层面的"精益过程流"角色。
- #09 新乡：SMED + Poka-Yoke 防错，源头不产生缺陷——过程层面的"防错 / 快速换模"角色。
- #12 赤尾洋二：QFD 质量屋，VOC → 技术需求——过程层面的"需求到设计展开"角色。
- #16 水野滋：QFD 共同提出者 + 新 QC 七工具——过程层面的"规划 / 策划工具"角色。
- #05 石川馨：因果图 + QC 七种 + 品管圈，全员参与——过程层面的"现场分析工具"角色。
- #18 哈默：BPR，流程根本性再设计——过程层面的"流程结构重构"角色。
- #19 哈林顿：BPM/BPI，可度量可持续的过程改进——过程层面的"过程管理"角色。

**代表著作**
- #5 丰田生产方式（大野耐一，TPS：JIT + 自働化）

- #19 质量机能展开 / #B02 质量功能展开——理论与方法（熊伟 / 马跃，QFD 质量屋）

**代表案例**

## 四、改进层面（Improvement）：持续改进与突破

**定义**：改进层面以 PDCA 为底层节奏，通过渐进改善（Kaizen）与突破式改进（六西格玛 / Red X / 8D）结合，把一次性解题变为可复制、可闭环的组织能力。它回答"问题出现后如何既治标又治本、并防止复发"的问题。

**代表人物**
- #11 今井正明：Kaizen 改善，持续小幅改进——改进层面的"渐进改善"角色。
- #10 比尔·史密斯：六西格玛之父，DMAIC + 3.4ppm——改进层面的"突破式改进（DMAIC）"角色。
- #15 Mikel Harry：六西格玛推广者与架构师，构建战略级改进体系——改进层面的"六西格玛架构化"角色。
- #13 谢宁：Red X，高级根因定位——改进层面的"顽固根因突破"角色。
- #04 克劳士比：零缺陷，质量免费——改进层面的"零缺陷文化 / 14 步"角色。
- #08 大野耐一：TPS 消除浪费——改进层面的"精益改善"角色。
- #01 休哈特：PDSA 雏形——改进层面的"改进循环骨架"角色。

**代表著作**
- #8 六西格玛管理统计指南（MINITAB，六西格玛 DMAIC 统计落地）
- #13 精益六西格玛（LSS，精益速度 + 六西格玛变异控制合一）
- #11 零缺陷（Quality Without Tears，克劳士比，无争执管理实现零缺陷）
- #6 精益思想（Lean Thinking，Womack & Jones，精益五原则）
- #15 质量管理传奇（汪泉发 等，系统梳理大师思想演变）

**代表案例**
- 六西格玛项目（某通信科技龙头 / 通用）：以 DMAIC 做数据驱动突破性改进，黑带 / 绿带梯队沉淀改进能力——突破式改进标杆。
- Kaizen（今井正明）：Gemba 现场改善 + 5S + 提案改善，全员日常渐进改进。
- 航空宇航双归零（改进闭环）：技术归零五条 + 管理归零五条，遵循 PDCA 把单次问题转化为组织级预防资产（books #37 归零）。
- 8D（汽车，福特）：团队导向八步法根因分析与闭环，适用客户投诉 / 重大异常。

**工具应用**

## 第四部分：现场管理 GK

# 日系现场管理（GK）体系 · 通用方法论蒸馏

> 本篇蒸馏自公开发表的管理体系方法论，内化为通用现场管理范式。

GK = Genba Kanri（现场管理 / 现地现物管理）。它是源自某日系车企生产方式（NPW，某日系车企生产体系的现场管理组成）的现场管理方法论，被誉为"生产管理的基石"。其本质是：以**品质管理为核心**，把一切管理活动拉到现场（Genba），通过标准化与显现化彻底消除浪费。GK 的一大特点是"凡事有基准"——**基准的有无**是 GK 现场诊断的起点：先问"这件事有没有标准/基准"，没有就先立基准，再谈改善。

---

## ① 定义与基本思想

- **Genba Kanri（现场管理）**：到发生价值创造的"现场"去管理。现场是产品与质量真正被制造出来的地方，管理决策必须回到现场、用事实说话（现地现物）。
- **源自 NPW 的现场管理组成**：作为某日系车企生产方式的现场落地层，GK 把 TPS 式的改善文化下沉到班组与工位，强调"管理是看得见的"。
- **以品质管理为核心**：GK 不是单纯的生产效率工具，而是把质量防线前移到工序与岗位，用"不制造不良"替代"检出不良"。
- **基准有无是诊断起点**：GK 诊断第一问永远是"这件事有基准吗"。无基准 → 先建基准；有基准 → 看是否遵守、是否最优。这使管理从"凭经验/拍脑袋"转为"凭基准/凭数据"。

---

## ② 核心模块

| 模块 | 要点 |
|---|---|
| 标准化 | 用表单、看板把作业标准"显现化"（原版现场表单上百项），让标准成为可观察、可审计的对象 |
| 作业观察 | 管理者定期到现场观察作业是否按标准执行，是 GK 最日常的抓手 |
| N-TWI | 一线训练体系（TWI 的现场化扩展），确保"会做的人把标准教给要做的人" |
| 三不原则 | 不制造不良品、不流出不良品、不接受不良品——质量防线的三道闸 |
| QCDMS | 质量(Q)·成本(C)·交付(D)·士气(M)·安全(S) 五维现场指标，把质量嵌入经营全维度 |
| 改善 Kaizen | 持续的小步快跑改善，人人参与、日日改善 |
| QC 小组 / 品质圈 | 一线自发组成的质量改进小组，把问题消灭在工位 |
| 班组长一日管理 | 班组长从班前会→过程巡线→异常处置→班后小结的标准一日节奏，是现场落地的总抓手 |
| 异常管理 | 异常"停得下来、看得明白、改得彻底"——安灯/andon、目视化、快速响应 |
| 5S | 整理/整顿/清扫/清洁/素养，现场秩序的基础，也是显现化的前提 |

---

## ③ SQGK（供应商现场管理）

SQGK = Supplier Genba Kanri，即把 GK 现场管理延伸到供应链：

- 不是只做来料检验（IQC），而是**协助供应商把现场管理建起来**——帮供应商立基准、做作业观察、跑三不原则、上 QC 小组。
- 通过供应商现场 audit + 共同改善，把"来料不良"转化为"工序能力不良为零"。
- 与 QCM 的 `governance.md`（供应商审核 / 供应商记分卡 / 来料 AQL 抽样 / SQE / 质量成本）形成互补：GK 提供"怎么帮供应商管现场"，治理地图提供"公司在供应链质量上的职责与 Gate"。

## ⑥ 可借鉴点（通用，不绑定具体企业）

1. **标准化基准是诊断起点**：遇到现场问题，先问"有基准吗"。无基准先建基准，有基准查遵守——这是把管理从"救火"转为"防火"的第一步。
2. **表单 / 看板显现化让问题可视化**：标准、异常、指标都要"贴到墙上、落到工位"，看不见的问题无法被管理。
3. **班组长一日管理是现场落地抓手**：再好的体系也要靠班组长每天的班前会→巡线→异常处置→班后小结跑起来。
4. **三不原则是质量防线**：不制造、不流出、不接受不良，配合 Poka-Yoke 把防线工程化。
5. **QCDMS 把质量嵌入经营全维度**：质量不是 QA 一家的事，而是与成本、交付、士气、安全并列的现场经营指标。
6. **SQGK 把现场管理延伸至供应链**：质量竞争力 = 自身现场能力 × 供应商现场能力，帮供应商建 GK 比加严来料检验更治本。

## ⑦ 现场管理者软技能模块（班组长能力育成）

GK 的现场落地最终靠"人"——尤其班组长 / 一线管理者。通用 GK 培训体系把现场管理者的能力拆为**硬技能（质量工具）+ 软技能（报告 / 沟通 / 问题解决 / 角色认知 / 流程）**两条线。以下 5 个模块是公开发表的现场管理培训标准课程，内化为通用范式（不绑定任何企业），可与本 Skill 的 `masters.md`、`knowledge-base.md`、`governance.md` 打通。

### 7.1 报告制作（A3 化、简洁易懂）

把信息做成"使用者能尽快理解、能引发建设性讨论、有问题也易被指出的资料"，同时倒逼制作者自检思路。

- **五步法**：① 明确目的（面向谁 / 如何使用 / 何种用途 / 传达什么）→ ② 撰写纲要（每步一句话标题 + 3 个左右理由/数据，检查现场现物与因果）→ ③ 确定版面（按纲要设文本框流程、留白对齐、重点多分配）→ ④ 撰写内容（简明·具体·主动语态，图表明示化）→ ⑤ 检查校对（按问题解决流程、外观均衡、含对象/日期/提交人）。
- **资料类型框架**：报告型（事实→对策→及时报告）、汇报型（背景→目标→现状→对策→结果→下一步）、提交审批型（问题—解决步骤—原因对策—决策事项）、提议型（背景→目标→现状→措施→实施→事例→结果→遗留）、问题解决型（明确问题→把握现状→设目标→真因→对策含担当/日程）。
- **A3 报告**：一页纸收敛"明确问题/分解/设目标/把握真因/制定对策/效果确认/评价巩固"，视觉化加速决策。
- **图表四式**：柱状图比绝对值、折线图看趋势、圆环图比整体占比、条形图看项目构成比；注意不同单位同图易误判、纵轴 0 起点影响观感、取值区间影响解读。

### 7.2 有效沟通（报联商 Hō-Ren-Sō）

现场管理沟通的核心是**报告（報告 / Report）· 联络（連絡 / Inform）· 商谈（相談 / Consult）**三位一体，源自日系现场管理惯例。

| 主题 | 定义 | 时机 | 要点 |
|---|---|---|---|
| 报告 | 就企划、进展、结果、改善方案沟通 | 企划/实施中/有结果/改善后 | 接受指示即确认报告日、催促前报告、5W2H、结论→理由→有条理 |
| 联络 | 把业务经过与问题及时反馈相关人员 | 紧急事态/恶化/事项变更 | 第一时间迅速联络、按紧急度确认方式、确认内容已传达到位 |
| 商谈 | 权限内难决断时带自己意见向上确认 | 不能理解指示/难判方案/独自无法解决 | 预约面对面、整理要点、带对策、结果必反馈 |

- **上下级沟通模型（PDCA 贯穿）**：P 接受指示（5W2H 确认→收集信息→预约上级时间→做企划案→报告商谈）；D 按计划推进（紧急变化即时联络、定期报告、需决策前商谈）；C 结果报告（汇总结果+改善方向）；A 改善报告（做具体改善案→标准化手册）。
- **同事 / 部门间沟通**：同事间做共同日程表实现可视化、周例会同步；部门间明确拜托目的→确认对方负荷→上级正式拜托函→定期会议共享进展。
- **沟通能力三角形**：对上级=报告+联络+商谈；对同事=联络+商谈；对部门=报告+联络；扩大三角面积即提升整体沟通能力。

> **扩展明细（报联商完整版）**：本节为 GK 软技能模块的"报联商"速查。报告·联络·商谈的**完整定义 + 对象 + 时机 + 特征 + 时间形式 + 要点 + PDCA 指示确认全流程 + 使用提示**，见独立知识文档 `business-communication-hourensou.md`（同属 `references/knowledge/` 知识族，经 `corpus_loader` 按锚点/关键词按需检索可达：`load_section("business-communication-hourensou", "PDCA 指示确认与闭环流程")` 或 `search_corpus("报连相")`）。两者主题同源——本节是"何时用哪个/三角模型"的精炼，该文档是"怎么用/全流程节点"的展开，互补而非重复。

### 7.3 问题分析与解决（界定→要因→方案→落地）

问题 = 现实与期望的差距。四阶段闭环：

- **① 界定问题**：发现异常（维度：重要性/紧急性/变化趋势）→ 优选矩阵排优先级 → 用信息·事实·数字描述现状 → 设目标期望值（案例陈述：现状 vs 理想状态 + 差距=问题）。
- **② 要因分析**：头脑风暴（轮流发言/数量重于质量/不编辑）→ 结构细化（演绎+归纳，MECE 不重不漏，上下对应、分类清楚）→ 鱼骨图（人机料法环）→ 内部归因（区分原因/理由/借口；影响圈 vs 关注圈，聚焦可控）→ 二八原则选重点（关键少数）。
- **③ 确认方案**：建备选（时间/有效性/可行性/成本一览表排序）→ 细化行动（动词+任务+衡量标准+期限）→ 融入创新（"还有什么方法"）→ 有效确认。
- **④ 落地执行**：制定计划（完整方案+获相关方同意+资源到位+监督进展）→ 预控风险（思考不利因素预警）→ 过程反馈（积极性/建设性反馈）→ 总结提升（PDCA：维持与改善平衡，固化标准）。

> 与 `knowledge-base.md` 的柏拉图/鱼骨图/5why/8D 实例、QC 七工具、5W2H/4M 一脉相承；A3 报告是上述四阶段的一页纸收敛载体。

### 7.4 角色能力成长（技能·认知·行为基础）

现场管理者能力三维模型：

- **技能维**：工作知识（质量/工艺/产品/测量/数理）+ 事实分析（质量会议·周月报·QC 手法·5W1H·三现五原则·8D）+ 协作沟通（同上）+ 改善改进（5S·防错·QCC·岗位标准化·目视化看板）+ 专业技能（精益·5S·FMEA·APQP·JIT·GK）。
- **认知维（自我管理）**：自我认知（职业心态/性格/能力）+ 自我约束（情绪/礼仪/形象）+ 自我成长（目标/计划/时间/职业规划/自我激励/人际管理）。
- **行为基础**：角色认知（定位·任务·角色）+ 职责知识（岗位职责·工作表单）+ 制度流程（流程·制度·文化）。
- **质量能力成长课程（三阶段）**：
  - 事前预防（技术开发/产品设计角色）：DFMEA·QFD·FTA·有效问题解决·CMMI 为掌握重点；
  - 事中控制（工艺开发/生产采购角色）：PFMEA·SPC·MSA·有效审核·分层审核为掌握重点；
  - 事后检验维护（质量验证/售后角色）：PFMEA·SPC·MSA·有效审核·分层审核 + ISO45001/14001/27001。
- **能力育成路径**：教育（制度/安全/观念，课堂+笔试）→ 培训（工具/操作/质量/项目，演示+实操）→ 管理体系育成（专业讲师+资格认定+再培训），为企业输出专业质量人才。

### 7.5 流程管理（端到端、ECRS 优化）

流程 = 一组共同为客户/企业创造价值的相互关联活动进程；本质是组织经营基础（人·任务·分工·方法·信息·流向·配置·质量协作）。

- **流程思维**：价值思维·协作思维·全局思维·跨部门端到端协作；价值=管理属性（效率）× 价值属性（效果）。
- **分层与分类**：按基本活动（市场/销售/交付/客服）与支持活动（资源/质量/运营/人力/信息）建流程清单；分战略/经营/支持、核心/辅助；按改进收益×风险识别关键流程；企业过程分顾客导向过程 COP / 支持过程 SP / 管理过程 MP。
- **能力建设闭环**：诊断 + 规划 + 设计 + 执行 + 审计 + 迭代（低成本快速试错、定期/快速迭代）。
- **优化工具 ECRS**：取消（Eliminate）· 合并（Combine）· 重排（Rearrange）· 简化（Simplify）· 整合（Standardize）；辅以乌龟图（输入/输出/人财物/设备/方法界定过程）。
- **流程设计七步**：要素识别 → 对象价值识别 → 流程图 → 流程说明 → 绩效指标 → 运作机制 → 流程文件。
- **制造质量流程（PDCA+S）**：P 过程策划（PFMEA/控制计划/作业指导书/防错）；D 过程运行（标准化作业/不合格品控制/变更控制）；C 过程监控（分层审核/CTQ/异常反馈/过程能力评审）；A 改善改进（快速响应/问题分析/持续改进）；S 资源支持（设备/测量/环境/仓储/来料/人员能力）。

> 流程管理衔接 `governance.md` 的公司级治理地图（价值链 Gate 闭环）与 `knowledge-base.md` 的 BPR/BPM（哈默/哈林顿）系统方法论；ECRS 与 TPS 消除浪费同源。

```
外部素材（书/案例/PPT/调研）→ QCM 知识库入库标准:
  ① 来源标注: [类型:一手|二手|调研] [可信:A|B|C]
  ② 结构统一: 核心做法 + 代表工具/方法 + 可借鉴点 + 来源
  ③ 映射落地: 至少映射1个 QCM 模块（六步导航/MDS/工具/大师）
  ④ 编号兼容: 引用工具#/人物#/决策①-㉑ 原编号
  ⑤ 黑名单: 知乎/公众号/百度百科 不采信为权威源
  ⑥ 入库位置: 本文件（knowledge-base.md）对应部分追加
```

### 6.3 应用约束（不破坏 QCM 结构）

```
✅ 允许: 知识/素材追加到本文件（仅扩展外部资产层）
✅ 允许: 调取时组合 QCM 模块输出
❌ 禁止: 修改 SKILL.md 核心决策/导航协议/MDS 定义
❌ 禁止: 素材内容覆盖 QCM 原生工具/大师定义
✅ 原则: 外部知识服务 QCM，不重构 QCM
```

### 6.4 覆盖监控

```
素材覆盖率 = 已映射素材 / 全部素材
知识引用率 = 知识库被调取次数（跟踪使用价值）
新增素材 → 按 6.2 规则蒸馏 → 追加对应部分 → 更新目录
```
