GK = Genba Kanri（现场管理 / 现地现物管理）。它是源自某日系车企生产方式（NPW，某日系车企生产体系的现场管理组成）的现场管理方法论，被誉为"生产管理的基石"。其本质是：以**品质管理为核心**，把一切管理活动拉到现场（Genba），通过标准化与显现化彻底消除浪费。GK 的一大特点是"凡事有基准"——**基准的有无**是 GK 现场诊断的起点：先问"这件事有没有标准/基准"，没有就先立基准，再谈改善。

---

## ① 定义与基本思想

- **Genba Kanri（现场管理）**：到发生价值创造的"现场"去管理。现场是产品与质量真正被制造出来的地方，管理决策必须回到现场、用事实说话（现地现物）。
- **源自 NPW 的现场管理组成**：作为某日系车企生产方式的现场落地层，GK 把 TPS 式的改善文化下沉到班组与工位，强调"管理是看得见的"。
- **以品质管理为核心**：GK 不是单纯的生产效率工具，而是把质量防线前移到工序与岗位，用"不制造不良"替代"检出不良"。
- **基准有无是诊断起点**：GK 诊断第一问永远是"这件事有基准吗"。无基准 → 先建基准；有基准 → 看是否遵守、是否最优。这使管理从"凭经验/拍脑袋"转为"凭基准/凭数据"。

## ② 核心模块

| 模块 | 要点 |
|---|---|
| 标准化 | 用表单、看板把作业标准"显现化"（原版现场表单上百项），让标准成为可观察、可审计的对象 |
| 作业观察 | 管理者定期到现场观察作业是否按标准执行，是 GK 最日常的抓手 |
| N-TWI | 一线训练体系（TWI 的现场化扩展），确保"会做的人把标准教给要做的人" |
| 三不原则 | 不制造不良品、不流出不良品、不接受不良品——质量防线的三道闸 |
| QCDMS | 质量(Q)·成本(C)·交付(D)·士气(M)·安全(S) 五维现场指标，把质量嵌入经营全维度 |
| 改善 Kaizen | 持续的小步快跑改善，人人参与、日日改善 |
| QC 小组 / 品质圈 | 一线自发组成的质量改进小组，把问题消灭在工位 |
| 班组长一日管理 | 班组长从班前会→过程巡线→异常处置→班后小结的标准一日节奏，是现场落地的总抓手 |
| 异常管理 | 异常"停得下来、看得明白、改得彻底"——安灯/andon、目视化、快速响应 |
| 5S | 整理/整顿/清扫/清洁/素养，现场秩序的基础，也是显现化的前提 |

## ③ SQGK（供应商现场管理）

SQGK = Supplier Genba Kanri，即把 GK 现场管理延伸到供应链：

- 不是只做来料检验（IQC），而是**协助供应商把现场管理建起来**——帮供应商立基准、做作业观察、跑三不原则、上 QC 小组。
- 通过供应商现场 audit + 共同改善，把"来料不良"转化为"工序能力不良为零"。
- 与 QCM 的 `references/governance.md`（供应商审核 / 供应商记分卡 / 来料 AQL 抽样 / SQE / 质量成本）形成互补：GK 提供"怎么帮供应商管现场"，治理地图提供"公司在供应链质量上的职责与 Gate"。

## ⑥ 可借鉴点（通用，不绑定具体企业）

1. **标准化基准是诊断起点**：遇到现场问题，先问"有基准吗"。无基准先建基准，有基准查遵守——这是把管理从"救火"转为"防火"的第一步。
2. **表单 / 看板显现化让问题可视化**：标准、异常、指标都要"贴到墙上、落到工位"，看不见的问题无法被管理。
3. **班组长一日管理是现场落地抓手**：再好的体系也要靠班组长每天的班前会→巡线→异常处置→班后小结跑起来。
4. **三不原则是质量防线**：不制造、不流出、不接受不良，配合 Poka-Yoke 把防线工程化。
5. **QCDMS 把质量嵌入经营全维度**：质量不是 QA 一家的事，而是与成本、交付、士气、安全并列的现场经营指标。
6. **SQGK 把现场管理延伸至供应链**：质量竞争力 = 自身现场能力 × 供应商现场能力，帮供应商建 GK 比加严来料检验更治本。

> 实战落地可结合本 Skill 的通用实战推演 `references/workshop.md`（8 大高频车间/场景 × 20 工具，含 5why/5w2h/4M 三面贯穿）与行业友商对标 `references/cases.md`。

## ⑦ 现场管理者软技能模块（班组长能力育成）

GK 的现场落地最终靠"人"——尤其班组长 / 一线管理者。通用 GK 培训体系把现场管理者的能力拆为**硬技能（质量工具）+ 软技能（报告 / 沟通 / 问题解决 / 角色认知 / 流程）**两条线。以下 5 个模块是公开发表的现场管理培训标准课程，内化为通用范式（不绑定任何企业），可与本 Skill 的 `people/`、`tools-examples.md`、`governance.md` 打通。

### 7.1 报告制作（A3 化、简洁易懂）

把信息做成"使用者能尽快理解、能引发建设性讨论、有问题也易被指出的资料"，同时倒逼制作者自检思路。

- **五步法**：① 明确目的（面向谁 / 如何使用 / 何种用途 / 传达什么）→ ② 撰写纲要（每步一句话标题 + 3 个左右理由/数据，检查现场现物与因果）→ ③ 确定版面（按纲要设文本框流程、留白对齐、重点多分配）→ ④ 撰写内容（简明·具体·主动语态，图表明示化）→ ⑤ 检查校对（按问题解决流程、外观均衡、含对象/日期/提交人）。
- **资料类型框架**：报告型（事实→对策→及时报告）、汇报型（背景→目标→现状→对策→结果→下一步）、提交审批型（问题—解决步骤—原因对策—决策事项）、提议型（背景→目标→现状→措施→实施→事例→结果→遗留）、问题解决型（明确问题→把握现状→设目标→真因→对策含担当/日程）。
- **A3 报告**：一页纸收敛"明确问题/分解/设目标/把握真因/制定对策/效果确认/评价巩固"，视觉化加速决策。
- **图表四式**：柱状图比绝对值、折线图看趋势、圆环图比整体占比、条形图看项目构成比；注意不同单位同图易误判、纵轴 0 起点影响观感、取值区间影响解读。

### 7.2 有效沟通（报联商 Hō-Ren-Sō）

现场管理沟通的核心是**报告（報告 / Report）· 联络（連絡 / Inform）· 商谈（相談 / Consult）**三位一体，源自日系现场管理惯例。

| 主题 | 定义 | 时机 | 要点 |
|---|---|---|---|
| 报告 | 就企划、进展、结果、改善方案沟通 | 企划/实施中/有结果/改善后 | 接受指示即确认报告日、催促前报告、5W2H、结论→理由→有条理 |
| 联络 | 把业务经过与问题及时反馈相关人员 | 紧急事态/恶化/事项变更 | 第一时间迅速联络、按紧急度确认方式、确认内容已传达到位 |
| 商谈 | 权限内难决断时带自己意见向上确认 | 不能理解指示/难判方案/独自无法解决 | 预约面对面、整理要点、带对策、结果必反馈 |

- **上下级沟通模型（PDCA 贯穿）**：P 接受指示（5W2H 确认→收集信息→预约上级时间→做企划案→报告商谈）；D 按计划推进（紧急变化即时联络、定期报告、需决策前商谈）；C 结果报告（汇总结果+改善方向）；A 改善报告（做具体改善案→标准化手册）。
- **同事 / 部门间沟通**：同事间做共同日程表实现可视化、周例会同步；部门间明确拜托目的→确认对方负荷→上级正式拜托函→定期会议共享进展。
- **沟通能力三角形**：对上级=报告+联络+商谈；对同事=联络+商谈；对部门=报告+联络；扩大三角面积即提升整体沟通能力。

### 7.3 问题分析与解决（界定→要因→方案→落地）

问题 = 现实与期望的差距。四阶段闭环：

- **① 界定问题**：发现异常（维度：重要性/紧急性/变化趋势）→ 优选矩阵排优先级 → 用信息·事实·数字描述现状 → 设目标期望值（案例陈述：现状 vs 理想状态 + 差距=问题）。
- **② 要因分析**：头脑风暴（轮流发言/数量重于质量/不编辑）→ 结构细化（演绎+归纳，MECE 不重不漏，上下对应、分类清楚）→ 鱼骨图（人机料法环）→ 内部归因（区分原因/理由/借口；影响圈 vs 关注圈，聚焦可控）→ 二八原则选重点（关键少数）。
- **③ 确认方案**：建备选（时间/有效性/可行性/成本一览表排序）→ 细化行动（动词+任务+衡量标准+期限）→ 融入创新（"还有什么方法"）→ 有效确认。
- **④ 落地执行**：制定计划（完整方案+获相关方同意+资源到位+监督进展）→ 预控风险（思考不利因素预警）→ 过程反馈（积极性/建设性反馈）→ 总结提升（PDCA：维持与改善平衡，固化标准）。

> 与 `tools-examples.md` 的柏拉图/鱼骨图/5why/8D 实例、QC 七工具、5W2H/4M 一脉相承；A3 报告是上述四阶段的一页纸收敛载体。

### 7.4 角色能力成长（技能·认知·行为基础）

现场管理者能力三维模型：

- **技能维**：工作知识（质量/工艺/产品/测量/数理）+ 事实分析（质量会议·周月报·QC 手法·5W1H·三现五原则·8D）+ 协作沟通（同上）+ 改善改进（5S·防错·QCC·岗位标准化·目视化看板）+ 专业技能（精益·5S·FMEA·APQP·JIT·GK）。
- **认知维（自我管理）**：自我认知（职业心态/性格/能力）+ 自我约束（情绪/礼仪/形象）+ 自我成长（目标/计划/时间/职业规划/自我激励/人际管理）。
- **行为基础**：角色认知（定位·任务·角色）+ 职责知识（岗位职责·工作表单）+ 制度流程（流程·制度·文化）。
- **质量能力成长课程（三阶段）**：
  - 事前预防（技术开发/产品设计角色）：DFMEA·QFD·FTA·有效问题解决·CMMI 为掌握重点；
  - 事中控制（工艺开发/生产采购角色）：PFMEA·SPC·MSA·有效审核·分层审核为掌握重点；
  - 事后检验维护（质量验证/售后角色）：PFMEA·SPC·MSA·有效审核·分层审核 + ISO45001/14001/27001。
- **能力育成路径**：教育（制度/安全/观念，课堂+笔试）→ 培训（工具/操作/质量/项目，演示+实操）→ 管理体系育成（专业讲师+资格认定+再培训），为企业输出专业质量人才。

### 7.5 流程管理（端到端、ECRS 优化）

流程 = 一组共同为客户/企业创造价值的相互关联活动进程；本质是组织经营基础（人·任务·分工·方法·信息·流向·配置·质量协作）。

- **流程思维**：价值思维·协作思维·全局思维·跨部门端到端协作；价值=管理属性（效率）× 价值属性（效果）。
- **分层与分类**：按基本活动（市场/销售/交付/客服）与支持活动（资源/质量/运营/人力/信息）建流程清单；分战略/经营/支持、核心/辅助；按改进收益×风险识别关键流程；企业过程分顾客导向过程 COP / 支持过程 SP / 管理过程 MP。
- **能力建设闭环**：诊断 + 规划 + 设计 + 执行 + 审计 + 迭代（低成本快速试错、定期/快速迭代）。
- **优化工具 ECRS**：取消（Eliminate）· 合并（Combine）· 重排（Rearrange）· 简化（Simplify）· 整合（Standardize）；辅以乌龟图（输入/输出/人财物/设备/方法界定过程）。
- **流程设计七步**：要素识别 → 对象价值识别 → 流程图 → 流程说明 → 绩效指标 → 运作机制 → 流程文件。
- **制造质量流程（PDCA+S）**：P 过程策划（PFMEA/控制计划/作业指导书/防错）；D 过程运行（标准化作业/不合格品控制/变更控制）；C 过程监控（分层审核/CTQ/异常反馈/过程能力评审）；A 改善改进（快速响应/问题分析/持续改进）；S 资源支持（设备/测量/环境/仓储/来料/人员能力）。

> 流程管理衔接 `governance.md` 的公司级治理地图（价值链 Gate 闭环）与 `methods.md` 的 BPR/BPM（哈默/哈林顿）系统方法论；ECRS 与 TPS 消除浪费同源。
