## 二、问题分析与解决 ↔ QCM 主流程映射（核心）

### 四阶段 ↔ 六步导航映射

| PPT 阶段 | PPT 内容 | QCM 模块 | 六步导航落点 | MDS 字段 |
|---------|---------|---------|------------|---------|
| **①界定问题** | 发现异常维度/优选矩阵(重要/紧急/变化)/现状描述/目标期望/差距陈述 | 决策-L2 ⑦四步穿透 + F5 PDCA | 第0步端到端 + 第2步内轴P | F5(5W2H)+F12+F11 |
| **②要因分析** | 列举要素/演绎归纳/MECE/鱼骨图/内部归因/影响圈/选择重点(柏拉图) | 决策-L3 ⑪多链融合 + 工具#5鱼骨/柏拉图 | 第2.5步多链筛选 | F7+F8 |
| **③确认方案** | 备选方案(时间/有效性/可行性/成本)/细化行动/创新/有效确认 | 决策-L2 ④选范式 + 控制层级⑱ | 第1步外轴 | F3+F4 |
| **④落地执行** | 制定计划/预控风险/过程反馈/总结提升(维持与改善平衡) | 决策-L4 ⑭自适应 + SDCA | 第5步取物+六步链 | F14-F17 |

## 三、报告制作 ↔ QCM 输出表达模块映射

| PPT 步骤 | PPT 内容 | QCM 模块 | 应用 |
|---------|---------|---------|------|
| Step1 明确目的 | 报告型(事实→对策→报告)/汇报型(背景→目标→现状→对策→结果→计划)/审批型(问题→解决→原因→决策) | 输出模板 L1-L3 | 按类型选模板 |
| Step2 撰写纲要 | 纲要主体+3个理由/数据支撑 | 三要素(原则/流程/依据) | L2+ 输出结构 |
| Step3 版面设计 | 提议型(①背景②目标③现状→⑦结果)/问题解决型 | output-templates.md | 输出布局 |
| Step4 撰写内容 | 简明扼要/一行一内容/开门见山/图表选择 | 表达规范（严谨/禁浮夸） | 全部层级 |
| Step5 检查校对 | 按问题解决流程展开/5W1H核对 | 门控检查（第六章） | 输出前校验 |

### 报告类型 ↔ 输出模板映射

| PPT 报告类型 | QCM 输出模板 | 对应场景 |
|-------------|------------|---------|
| 报告型（事实→对策→报告） | L0 卡片（问题→根因→马上做） | 巡检/应急 |
| 汇报型（背景→目标→现状→对策→结果→计划） | L2 完整穿透模板 | 常规项目 |
| 审批型（问题→解决步骤→原因→决策） | L3 专家模板 | 组织级决策 |
| A3 一页纸报告（8步骤一页） | 导航头+取物摘要格式 | 精益汇报 |

## 五、应用调取方式

### 触发路由（SKILL.md 意图路由扩展）

| 用户请求 | 调取素材 |
|---------|---------|
| "怎么写报告/汇报材料" | 报告制作五步法 + 输出模板 |
| "怎么跟上级/同事沟通" | 有效沟通 PDCA 模型 |
| "问题分析/解决步骤" | 问题分析与解决四阶段 + 六步导航 |

### 调取示例

```
用户: 帮我分析设备发货延迟问题
→ 调取: 问题分析与解决 ①界定问题(优选矩阵+差距陈述)
      + QCM 六步导航 → MDS 填写 → 取物
输出: [六步导航摘要] + 差距陈述(现状14天→目标2天) + 柏拉图定位 + 8D方案
```

```
用户: 这份改善报告怎么写？
→ 调取: 报告制作 Step1-5 + QCM L2 输出模板
输出: 汇报型结构(背景→目标→现状→对策→结果→计划) + 图表选择指引
```
