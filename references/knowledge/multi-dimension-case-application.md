# 多链融合与多维交叉——质量工具应用案例输出模板

> **定位**：本文件定义 QCM 输出质量工具应用案例时的三维交叉分析框架（组织维度×流程维度×应用维度）。每个工具案例通过「四层穿透 × 四面交叉 × 多链根因 × 工具链串联 × 治理节拍」五个维度交叉输出，形成系统性工具应用画像。

## 输出框架（五维交叉，三维定位）

```
┌─────────────────────────────────────────────────────────────────┐
│                     工具案例：XXX                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ① 四层穿透（组织维度）── 该工具服务于组织哪一层？               │
│  ┌───┬───┬───┬───┐                                             │
│  │战略│管理│业务│执行│   每层标注 "主用" / "辅用" / "交叉引用"   │
│  └───┴───┴───┴───┘                                             │
│                                                                 │
│  ② 四面交叉（流程维度）── 该工具落在流程哪个面？               │
│  系统面 ←→ 管理面 ←→ 过程面 ←→ 产品面                          │
│  (体系设计)  (过程管控)  (工艺参数)  (实物质量)                   │
│                                                                 │
│  ③ 多链根因（应用维度）── 仿 3A5WHY 三链结构：                │
│    ├─ 发生链：工具如何预防问题发生？                            │
│    ├─ 流出链：工具如何拦截问题流出？                            │
│    └─ 系统链：工具如何封堵体系允许？                            │
│                                                                 │
│  ④ 工具链串联 ── 本工具在工具链中的位置：                     │
│    上游工具 → [本工具] → 下游工具                                │
│                                                                 │
│  ⑤ 治理节拍 ── 该工具的使用频次/场合：                        │
│    年 / 季 / 月 / 周 / 班 / Hr                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 示例：SPC 控制图（完整五维交叉案例）

### ① 四层穿透（组织维度）

| 层 | 角色 | 说明 |
|----|------|------|
| 战略层 | ◇ 辅用 | COQ 分析引用 SPC 数据做战略决策；Cpk 趋势进入年度方针评审 |
| 管理层 | ◆ 主用 | 部门设定 SPC 判异规则、控制计划指定关键特性纳入 SPC、Cpk 为月度绩效指标 |
| 业务层 | ◆ 主用 | 现场 SPC 控制图监控关键尺寸/参数，判异后启动 QRQC/5why |
| 执行层 | ◇ 辅用 | 操作员按频次点绘控制图，发现趋势异常即反馈 |

### ② 四面交叉（流程维度）

```
系统面 → 过程设计时确定哪些关键特性纳入 SPC（控制计划→体系要求）
   ↓
管理面 → SPC 判异（8 条判异准则）→ 启动 QRQC 闭环
   ↓
过程面 → 采集点绘数据来自实际生产过程（工艺参数、尺寸测量）
   ↓
产品面 → SPC 判异最终保障产品实物质量合格（减少不合格品流出）
```

### ③ 多链根因（SPC 判异后分析）

| 链 | 分析路径 | 典型根因 |
|----|---------|---------|
| **发生链** | 为什么出现异常？ | 刀具磨损→换刀频次不足→TPM 制度缺口 |
| **流出链** | 为什么 SPC 没提前预警？ | 抽样频率 1 次/4h，磨损在 2h 内→频次不够→控制计划未优化 |
| **系统链** | 为什么体系允许偏移？ | PFMEA 未评审历史数据→经验反馈机制缺失→体系闭环缺口 |

### ④ 工具链串联

```
PFMEA ──→ 控制计划 ──→ SPC ──→ Cpk 研究 ──→ QRQC
```

### ⑤ 治理节拍

| 频次 | 场合 | 执行角色 |
|------|------|---------|
| 每 1–2h | SPC 点绘 | 操作员 |
| 触发 | 判异响应 | IPQC / PQE |
| 每日 | SPC 日汇总 | IPQC |
| 每周 | Cpk 趋势 | PQE |
| 每季 | 控制限更新 | 质量工程师 |
| 每年 | SPC 特性评审 | 技术/质量 |

## 示例：8D 八步法（五维交叉案例）

### ① 四层穿透

| 层 | 角色 | 说明 |
|----|------|------|
| 战略层 | ◇ 辅用 | 8D 数据积累根因对策库，支撑供应商质量策略调整 |
| 管理层 | ◆ 主用 | 质量经理批准 8D 启动与关闭，8D 关闭率作为绩效指标 |
| 业务层 | ◆ 主用 | CQE/SQE 主导 8D 全流程，根本原因分析与措施验证 |
| 执行层 | ◆ 主用 | D3 围堵执行（库存/在途/在制），永久对策的实施操作 |

### ② 四面交叉

```
系统面 → D2 问题定义 + D7 预防再发（PFMEA/控制计划更新）
   ↓
管理面 → D0 应急/D4 根因确认/D5 措施批准→ 管理评审
   ↓
过程面 → D4 根因分析依赖过程工艺面数据（镀层/参数/记录）
   ↓
产品面 → D3 围堵（产品实物隔离）→ D6 验证 → 产品合格重新放行
```

### ③ 多链根因（客户端焊不上）

| 链 | 路径 | 根因 | 对策 |
|----|------|------|------|
| **发生链** | 焊不上→镀层不足→供应商参数偏移→无定期 XRF | 来料可焊性管控缺失 | 来料加可焊性检验门 |
| **流出链** | 焊不上到客户端→IQC 未拦截→无可焊性项→SIP 漏项 | 检验标准未覆盖 | 补充浸焊法测试 |
| **系统链** | 无规格→采购合同缺可焊性→准入审核缺镀层项 | 供应商准入体系漏洞 | 更新审核检查表 |

### ④ 工具链串联

```
QRQC ──→ 8D ──→ 3A5WHY ──→ Poka-Yoke ──→ PFMEA/CP 更新
```

### ⑤ 治理节拍

| 环节 | 时限 | 角色 |
|------|------|------|
| D0-D1 应急响应 | ≤ 24h | CQE |
| D3 围堵 | ≤ D2 | CQE+制造 |
| D4 根因分析 | D2-D4 | CQE+技术+SQE |
| D5-D6 纠正+验证 | D4-D8 | 责任部门 |
| D7 预防再发 | D8-D14 | CQE+体系 |
| D8 关闭+展开 | D14-D20 | 质量经理 |

## 使用说明

根据工具复杂度选择展开深度：

| 工具复杂度 | 展开维度 | 示例 |
|-----------|---------|------|
| 简单工具 | ①四层穿透 + ⑤治理节拍 | 检查表、红牌、5S |
| 中等工具 | ①+②+④+⑤ | 8D、SPC、FMEA、控制计划 |
| 复杂工具 | 全部五维 | 3A5WHY、六西格玛 DMAIC、APQP |
